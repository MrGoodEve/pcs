# pcs —— RS-FEC 解码链：规格版 / 参考版 对拍

PCS 层 RS-FEC 的实现与验证工程（**不属于 SerDes 内容**）。
两条**独立**的解码实现，加一个问答式 runner：**输入配置 → 两个都跑 → 对拍**，
任何"只有某一种写法才成立"的错误都藏不住。

## 快速开始

```bash
cd code
python runner.py                          # 问答式（不记得参数就用这个）
python runner.py --code fwd --nu 3 --seed 1
python runner.py --code rev --err 10:0x5A,370:0xA5 --trace
python runner.py --selftest
```

只用标准库，Python 3.8+ 即可。

### 配置项

| 参数 | 含义 | 备注 |
|---|---|---|
| `--code rev\|fwd` | 反向 RS(73,69,8) / 正向 RS(384,354,9) | 见下表 |
| `--nu N` | 注入错误个数 | `≤t` 应纠对；`>t` 触发失败判据或误纠 |
| `--seed N` | 随机种子 | 数据、错误位置、幅值都由它决定 |
| `--err p:v,...` | 手工指定错误 | `位置:误码值`，位置按**发送序** `0..n-1` |
| `--trace` | 打印规格版逐轮账目 | N、δ、L、B、b、H、修正块、Λout |
| `--selftest` | 跑一批组合看一致率 | 输出两实现一致率 + 判对率 |

## 两个实现的分工

| 步骤 | ① 规格版 `spec_impl` | ② 参考版 `ref_impl` |
|---|---|---|
| **BM 求 Λ** | 用户的 8 步（`B/b/L/H/C` + `C_len`，`L=max(⌈N/2⌉,C_len)`） | 教科书 BM（`C/B` + 年龄 `age`，成长时 `L←N−L`） |
| **Chien 定位** | 根形式 $\tilde\Lambda_j=\Lambda_{L-j}$，遍历 $x=\alpha^d,\ d=0..n-1$ | 直接代入 $\Lambda(\alpha^{-e})$，用折返指数 $\alpha^{2^\mu-e}$ |
| **幅值** | Forney：$E_i=\Omega(X_i^{-1})/\lambda'(X_i^{-1})$ | **解线性方程组**（Vandermonde + 高斯消元）——与 Forney 毫无关系 |
| 判据① $L\le t$ | ✓（提前中止，不跑 Chien/Forney） | —（参考版不查） |
| 判据② 根数 < deg Λ | ✓ | ✓ |
| 判据③ ∃j≥degΛ, Ω[j]≠0 | ✓ | —（Ω 属规格版口径，不引入以保持独立） |
| ~~判据④ 纠正后 S 全 0~~ | **已删**（与 ③ 等价、要重扫整块） | ✓（参考版保留，仍走一遍端到端） |

对拍项：**判定（成功/失败）**、Λ 逐系数、位置集合、幅值、纠正后码字、与注入真值是否一致。
判据**标签**允许不同（规格版按 ①/②/③ 提前返回，参考版只有 ②/④）——只比"是否判定失败"，runner 会打出一行说明。

## 码参数

| 名字 | 码 | 域 | 本原多项式 | FCR | k | 2t | n | t |
|---|---|---|---|---|---|---|---|---|
| `rev` | 反向 RS(73,69,8) | GF(2⁸) | $x^8+x^4+x^3+x^2+1$ = `0x1D` | 1 | 69 | 4 | 73 | 2 |
| `fwd` | 正向 RS(384,354,9) | GF(2⁹) | $x^9+x^4+1$ = `0x11` | 1 | 354 | 30 | 384 | 15 |

## 命名与口径（与笔记一致）

```
n  = 码字长度 = k + 2t          k = 信息符号数        h = 2t = 校验符号数
μ  = 域位宽 GF(2^μ)             α 的阶 = 2^μ − 1      FCR = 1
位置 p（0..n-1，发送序） ↔ 次数 d = n−1−p ↔ X = α^d ↔ Λ 的根 x = X^{-1} = α^{−d}
折返：α^{−d} = α^{(2^μ−1)−d}      遍历窗口（指数）= [2^μ−n, 2^μ−1]
传输序：整块降幂发送；p=0 是 x^(n-1)（最先发），p=n−1 是 x^0（最后发）
校验段：位置 k..n−1（与数据段一视同仁，Chien 照样命中）
```

## 已知边界（务必知道）

**1. 误纠不可检（ν>t 时）**
接收字可能离"另一个码字"比离原码字更近，有界距离解码按定义会跳到那一个：输出是**合法码字**、
伴随式**全 0**，判据②③④都没有可见异常，只有更高的上层（CRC / 协议层重传）能兜。

```bash
python runner.py --code rev --nu 3 --seed 9     # 两实现一致地"误纠"（位置 [65,54]）
python runner.py --code rev --nu 4 --seed 4
python runner.py --code rev --nu 8 --seed 20
```

**2. 判据①（$L\le t$）会触发**
只跑 $2t$ 轮并不意味着 $\deg\Lambda\le t$：末轮 $L=\max(⌈N/2⌉,C\_len)$，而 $C\_len$ 可达 $t+1$。
实测 rev 123/42000、fwd 17/13065 的用例 $L>t$（例 `--code rev --nu 3 --seed 215`：$L=3=t+1$）。
它同时是 $C$ 数组的越界护栏，故保留为判据并作提前中止（省 Chien/Forney）。
另外 $L\le N$ 恒成立（末轮 $N=2t$ ⇒ $L\le 2t$），但 **$L>t$ 可以出现在最后一轮之前**（少见，见 `reference/算法规格.md` §1）。

**3. 判据③ 会触发，④ 已删**
③ 实测 rev 10/10000（例 `--code rev --nu 3 --seed 424`），保留；④ 与 ③ 数学等价（0/14500 反例）却要重扫整块，规格版**已删**，参考版仍保留它作端到端对照。主力仍是②。

**4. 判据③的下标口径**
$\Omega[j]=\sum_{i\le j}S_{j-i+1}\lambda_i$（$S_k=0$ 当 $k\le0$），门槛是 $j\ge \deg\Lambda \Rightarrow \Omega[j]=0$。
若按笔误版写成 $\sum_i S_{j-i}\lambda_i$，同一门槛会**误杀正常用例**（实测：正向 3 错、$L=3$ 时 $\Omega[3]=\alpha^{14}\ne0$）。

## 复现口径

- 域表递推：`tbl[i+1] = tbl[i]<<1`；溢出 $2^\mu$ 时再异或 `(1<<μ) ^ poly`
- Λ′（char 2 形式导数）：只取**奇数下标**系数、整体右移一位 ⇒ **无乘法器**
- Forney 尺度因子：FCR=1 ⇒ $X^{1-\text{FCR}}=1$（本地 g(x) 的根为 $\alpha^1..\alpha^{2t}$，实测确认）
