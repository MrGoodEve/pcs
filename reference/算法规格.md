# 算法规格（定稿）—— RS 解码链：BM → Chien → Forney

> 这份是 `code/spec_impl.py` 的规格来源，也是 RTL 实现的口径卡。
> 记法：$n$ 码字长度，$k$ 信息符号数，$h=2t$ 校验符号数，$\mu$ 域位宽（$\mathrm{GF}(2^\mu)$），FCR=1。

---

## 0. 约定

| 量 | 约定 |
|---|---|
| 传输序 | 整块**降幂**发送：位置 $p=0$ 是 $x^{n-1}$（最先发），$p=n-1$ 是 $x^0$（最后发） |
| 位置 ↔ 次数 | $d = n-1-p$；$X=\alpha^{d}$ |
| $\Lambda$ 的根 | $x = X^{-1} = \alpha^{-d}$；折返 $\alpha^{-d}=\alpha^{(2^\mu-1)-d}$ |
| 遍历窗口（指数） | $[\,2^\mu-n,\ 2^\mu-1\,]$（共 $n$ 个连续指数，$2^\mu-1\equiv0$） |
| 校验段 | 位置 $k..n-1$，与数据段**一视同仁**（Chien 照样命中） |
| 域运算 | 乘除用 $\alpha$ 幂次表；加法 = 按位异或（**加法没有指数公式**） |
| $\Lambda'$ | char 2 的形式导数：$j\cdot\lambda_j$ 取 $j\bmod 2$ ⇒ 偶数项清零、奇数项保留 |
| **FCR** | 生成多项式**第一个根的指数**：$g(x)=\prod_{i=\text{FCR}}^{\text{FCR}+2t-1}(x\oplus\alpha^i)$。本码定 **FCR=1** ⇒ 根为 $\alpha^1..\alpha^{2t}$（narrow sense），Forney 尺度因子 $X^{1-\text{FCR}}=1$（省一次乘法） |

**FCR 口径（互通性关键，open 0.28）**：FCR 定死四件事——$g(x)$ 全部系数、校验码元 $P_0..P_{2t-1}$、伴随式求值点（$S_j=r(\alpha^{\text{FCR}+j-1})$）、Forney 尺度因子。**标准未规定它**（用 PDFium 抽全 124 页中文文本层复核：`FCR` / `PCS` / `PMA` 均 0 次命中）⇒ 必须与对端**约定一致**，否则要么整块报失败、要么"自信地纠成垃圾"。
对照：IEEE 802.3 Clause 91（91.4.2.9）明写 "the first root of the generator polynomial shall be 1 ($\alpha^0$)"，即 **802.3 是 FCR=0**，不能照搬到本码。
钉死 FCR 的硬办法：用标准或基线 RTL 里任一帧**示例码字**反算（802.3 的 Annex 91A 就是给示例码字来锁参数的）。

---

## 1. BM：求 $\Lambda$（8 步）

初值：$B=[1],\ b=1,\ L=0,\ H=0,\ C=[1],\ N=0$

$$
\begin{aligned}
&\text{①}\ N=N+1\\
&\text{②}\ \delta=\bigoplus_{i=0}^{L} S_{N-i}\otimes C_i\qquad (C_0=1;\ S_k=0\ \text{当}\ k\le 0)\\
&\text{③}\ \delta=0 \Rightarrow \text{⑧}\\
&\text{④}\ s=N-H\\
&\text{⑤}\ C\_tmp=[0]*s \oplus (\delta/b)\otimes B,\qquad C\_len=s+\mathrm{len}(B)-1\\
&\text{⑥}\ \text{if } 2L<N:\quad B=C,\quad L=\max\!\big(\lceil N/2\rceil,\ C\_len\big),\quad b=\delta,\quad H=N\\
&\text{⑦}\ C=C\oplus C\_tmp\\
&\text{⑧}\ N<2t \Rightarrow \text{①；否则结束}
\end{aligned}
$$

要点：

- **⑤ 的块长 = $\mathrm{len}(B)$**（不是 $L$）。$C\_len$ 是修正块顶到的位置。
- **⑦ 不裁剪高位 0**（0 占位）：数组长度只增不减，位置信息不能丢。
- **⑥ 的三个动作同支同时**：$L$ 增长、$B\!\leftarrow\!C$、$b,H$ 更新必须一起做；换早/换晚/不换都会坏。
- 恒等式（建议做成 RTL 断言）：$H=(\mathrm{len}(B)-1)+L$。实测 69000 轮 **0 违反**（轮首与增长轮都查）。
- **增长轮的新长度 = $N-L_{\mathrm{in}}$**（$L_{\mathrm{in}}$ = 本轮更新前的 $L$）；8 步版的 $\max(\lceil N/2\rceil,C\_len)$ 与教科书 BM 的 $L\leftarrow N-L$ 实测**逐例等值**（0 例外）。推论：$L\le N$ 恒成立 ⇒ 末轮 $L\le 2t$，**永远不会有 $L>2t$**。
- 但 **$L>t$ 可以出现在最后一轮之前**：实测 rev 用伴随式 $S=[0,0,\alpha^{52},\alpha^{17}]$（可由位置 0~3 的错误 $\alpha^{48},\alpha^{58},\alpha^{202},\alpha^{206}$ 产生，即一个真实接收字）得 $N=3$ 时 $L=3>t=2$；fwd 也有 $N=29$ 时 $L=16>15$ 的例子。真实码字 + 随机错误那批（7500 例）里 0 例在末轮前越界，全在 $N=2t$ 才越界 —— 所以①按轮检查只在极少数输入上能提前 1~2 轮，主要收益仍是跳过 Chien/Forney。

---

## 2. Chien：求位置

根形式 $\tilde\Lambda_j=\Lambda_{L-j}$，遍历 $x=\alpha^d,\ d=0..n-1$：

$$
\sum_{j=0}^{L}\tilde\Lambda_j\,(\alpha^d)^j = 0 \;\Longrightarrow\; \text{命中，位置 } p=n-1-d
$$

- RTL 写法：$x\leftarrow\alpha^0$ 起步、每拍 $\times\alpha$、共 $n$ 拍；每个系数配一个累加器，每拍每系数只乘一次常数。
- 根数必须 $\ge\deg\Lambda$，否则失败（见下）。

---

## 3. Forney：求幅值（FCR=1 ⇒ 尺度因子为 1）

$$
\Omega[j]=\sum_{i=0}^{\min(j,L)} S_{j-i+1}\otimes\lambda_i
\qquad (S_k=0\ \text{当}\ k\le0;\ j=0..2t-1)
$$

$$
\lambda'(x)=\sum_{j\ \text{odd}}\lambda_j\,x^{\,j-1}
\qquad
E_i=\frac{\Omega(X_i^{-1})}{\lambda'(X_i^{-1})}
$$

- 位置 $p_i=n-1-d_i$ 处的接收符号 $\mathrel{\oplus}=E_i$。
- 分母永不 0：$X_i$ 互异 ⇒ $\lambda'(X_i^{-1})=X_i\prod_{j\ne i}(1-X_j/X_i)\ne0$。
- 为什么是相除：$\Omega(x_i)=E_iX_i\prod_{j\ne i}(1-X_jX_i^{-1})$ 与 $\lambda'(x_i)=X_i\prod_{j\ne i}(\cdot)$ 共享同一"其余根因子"。

## 4. 失败判据

| # | 判定 | 口径与实测 |
|---|---|---|
| ① | 递推长度 $L\le t$（否则 fail） | **保留**：成本 = 1 个比较器，可在 Chien/Forney 之前提前中止（省功耗）；同时它就是 $C$ 数组的越界判断。**不恒假**：末轮 $L=\max(⌈N/2⌉,C\_len)$、$C\_len$ 可到 $t+1$，实测 rev 123/42000、fwd 17/13065 会触发（但都同时被 ② 拦下） |
| ② | Chien 根数 $<\deg\Lambda$ ⇒ fail | **主力**：实测 rev 9596/10000、fwd 4500/4500 的超能力用例由它拦下；同时是 Forney 分母非 0 的前置条件 |
| ③ | $\exists j\ge\deg\Lambda$ 使 $\Omega[j]\ne0$ ⇒ fail | **不可删**：拦下 ② 看不到的一类（实测 rev 10/10000，例 `--code rev --nu 3 --seed 424`） |
| ~~④~~ | ~~纠正后重算 $S\ne0$~~ | **已删**：与 ③ 数学等价（0/14500 反例），却要重扫整块 $n$ 拍，资源/功耗不值。若系统级要求端到端自检（RAM 读-改-写回、位置↔幅值配对），可作**可选输出门**复启用 |

**① 用递推长度 $L$；②③ 用 $\deg\Lambda$**：$C$ 是"0 占位、从不裁剪"的数组，最高次系数可能被 ⑦ 的异或抵消 ⇒ 会出现 $\deg\Lambda<L$（实测 rev 17/6000、fwd 2/1500；例 `--code rev --nu 3 --seed 424`：$L=2$、$\deg\Lambda=1$），反向 $\deg\Lambda>L$ 实测 0/7500。理由：②③ 判的是**多项式**（"根数 $=\deg\Lambda$ ⇒ 无重根 ⇒ Forney 分母非 0"、以及"纠正后是码字 ⟺ $\deg\Omega<\deg\Lambda$"）。RTL 上两个量都要留：$L$（或 $C\_len$）管数组深度与越界，$\deg\Lambda$ 管判据。

**口径警告（判据③）**：门槛是 $j\ge\deg\Lambda$（配 $\Omega[j]=\sum S_{j-i+1}\lambda_i$）。
若误写成 $\sum_i S_{j-i}\lambda_i$，同一门槛会**误杀正常用例**（实测：正向 3 错、$L=3$ 时 $\Omega[3]=\alpha^{14}\ne0$）。

**不可检的误纠**：$\nu>t$ 时接收字可能离另一个码字更近，解码照定义跳过去 ⇒ 输出是合法码字、$S$ 全 0，
判据①②③全过（④ 已删）但与真值不符。**只有上游（CRC / 重传）能兜**。实测比例：rev ν=3..12 × seed 1..1000 里误纠 3.9%、② 拦下 96.0%、③ 拦下 0.1%。

## 5. RTL 口径卡

| 项 | 结论 | 依据 |
|---|---|---|
| $C$ 深度 | $t+1$ 级（**仅对可纠输入成立**） | $\mathrm{len}(C)\le L+1$；可纠时 $L\le\nu\le t$。⚠ 超能力输入实测 $L$ 达 $t+1$、$\mathrm{len}(C)$ 达 $t+2$ ⇒ 降深到 $t+1$ 的前提是**写入高次系数前先做越界判断**（即判据①） |
| $B$ 深度 | $t$ 级 | 存档轮 $2L<N\Rightarrow L\le t-1$ |
| $b$ | 1 个符号寄存器 | — |
| 修正块 | 不需要单独数组：按偏移 $s$ 就地异或进 $C$ | $s+\mathrm{len}(B)=C\_len+1\le t+1$ |
| $\Lambda'$ | **无乘法器**：奇数下标右移一位，其余写 0 | char 2 形式导数 |
| Chien 窗口 | 指数 $[2^\mu-n,\ 2^\mu-1]$；$x\!\leftarrow\!1$ 起步 $n$ 拍 | 终点 $\alpha^{2^\mu-1}\equiv1$ |
| 域参数 | **配置期核对**（$m$、本原多项式、FCR、位序）；运行期无 $m$ 可检测 | 配错时靠判据③（根出窗）兜底 |
| 判据集合 | ①（$L\le t$：越界护栏 + 提前中止省功耗）+ ②（根数 $<\deg\Lambda$）+ ③（$\exists j\ge\deg\Lambda,\ \Omega[j]\ne0$）；**④ 已删** | §4；③④ 实测等价（0/14500 反例） |
| ② 的必要性 | 它是 Forney 可定义的**前置条件**：根数 $=\deg\Lambda$ ⇒ 无重根 ⇒ 分母 $\lambda'(X_i^{-1})\ne0$ | 实测 rev ν=1..12 × seed 1..500：② 命中 4807 例中有 **7 例**分母为 0（③④ 兜不住） |
