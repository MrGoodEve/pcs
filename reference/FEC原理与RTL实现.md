<a id="sec-1-1"></a>
### 1.1 冗余限制了哪些序列可以被发送

前向纠错（Forward Error Correction，简称 FEC）是发送端按约定的编码规则添加冗余、接收端利用这些约束纠正错误的方法。这里“前向”表示接收端依据当前收到的数据完成纠错，不必先请求发送端重传；本篇讨论的纠错保证始终带有错误数量上限。先用一个比特例子说明这套思路。

编码是把信息映射成允许发送的序列；这样的序列叫码字。接收端根据收到的序列选择码字并取回信息，叫译码。

记信息比特为 $u\in\{0,1\}$，编码后的发送串为 $c$，经过信道后的接收串为 $r$。如果只发送 $u$，接收端看到 1 时，无法区分“原来就是 1”和“0 被翻成 1”。增加规则：0 编成 000，1 编成 111。可发送的三比特串只剩两个。

异或（exclusive OR，简称 XOR）是两个比特不同输出 1、相同输出 0 的运算，记作 $\oplus$；串的异或逐位进行。定义错误串为发送串和接收串的差：$e=c\oplus r$。由于一个比特与自身异或为零，再异或一次 $c$，得到

$$r=c\oplus e.$$

收到 010 时，它与 000 只差一位，与 111 差两位。如果事先保证最多一位出错，可以唯一判断原来发送的是 000。这就是重复码的多数表决。

这不是给接收端增加了一份原文，而是增加了“发送串必须属于哪一小部分序列”的规则。若没有错误数限制，010 也可能由 111 经两位翻转产生，因此纠错保证必须带条件。

<a id="sec-1-2"></a>
### 1.2 码距怎样给出纠错半径

用 $\mathcal C$ 表示全部合法码字的集合，用正整数 $n$ 表示共同长度；任取两条等长串 $a=(a_0,\ldots,a_{n-1})$、$b=(b_0,\ldots,b_{n-1})$，接收串同样写为 $r=(r_0,\ldots,r_{n-1})$，下标 $i$ 表示零基位置。记设计允许纠正的错误位置数上限为非负整数 $t$。码距描述两个码字有多不一样。本篇按符号位置计数：两条等长串不同的符号位置数称为符号距离，也称 Hamming（汉明）距离；在某条串周围距离不超过 $t$ 的所有串构成半径 $t$ 的集合。定义

$$d(a,b)=\#\{i:a_i\ne b_i\},\qquad d_{\min}=\min_{a,b\in\mathcal C,\ a\ne b}d(a,b).$$

逐个位置看：如果 $a_i\ne b_i$，则 $r_i$ 不可能同时等于二者，所以这个位置至少在 $a$ 与 $r$、或 $r$ 与 $b$ 中贡献一次不同。将所有位置相加，就得到三角不等式

$$d(a,b)\le d(a,r)+d(r,b).$$

假设同一个接收串同时距离两个合法码字不超过 $t$，那么

$$d(a,b)\le t+t=2t.$$

如果码的最小距离至少为 $2t+1$，上述情况就不可能发生。因此在最多 $t$ 个错误的条件下，发送码字唯一。反过来，两个码字相距至多 $2t$ 时，可以把它们不同的位置分成两组，各不超过 $t$，拼出一个同时靠近二者的接收串。因此保证纠错的条件是

$$d_{\min}\ge2t+1.$$

纯检错则不同：若少于 $d_{\min}$ 个位置改变，不可能从一个合法码字直接变成另一个合法码字，所以能保证检测 $d_{\min}-1$ 个错误。这个结论说的是“检查收到的串是否合法”，不能直接套到已经做了纠错的输出上。

<a id="sec-1-3"></a>
### 1.3 为什么本文选择 RS 以及符号错误如何计数

里德–所罗门码（Reed–Solomon code，简称 RS）是一类对符号进行编码的纠错码；这里一个符号是由 $w$ 个比特组成、作为整体参与运算的字，而不是一个单独比特。它将信息和校验符号组成码字，利用第 3 章将要定义的多项式约束纠错。例如一个 8 比特符号从 `0x00` 变为 `0xFF`，虽然八个比特都变了，也只计为一个错误符号。八个位于不同符号的单比特错误，则可能计为八个错误符号。把本次实际错误符号数记为 $\nu$；它是信道造成的事实，接收端事先不知道。设计保证针对的是 $\nu\le t$，不能只看错误比特的总数。

一个码字共有 $n$ 个符号，其中 $k$ 个信息符号、$h=n-k$ 个冗余符号；这些数量都是整数。信息在全部发送符号中占的比例称为码率，定义为 $R=k/n$。本篇使用偶数个校验符号，设计上限取 $t=h/2$，其纠错保证将在第 4 章证明。

本文采用两组参数。表中域模的 $u$ 是用于表示比特位置的形式变量，具体算术在第 2.1 至 2.2 节定义：

| 教学参数组 | $n$ | $k$ | $w$ | $h$ | $t$ | 域模多项式 |
|---|---:|---:|---:|---:|---:|---|
| 小规模主算例 | 73 | 69 | 8 | 4 | 2 | $u^8+u^4+u^3+u^2+1$ |
| 较大硬件参数组 | 384 | 354 | 9 | 30 | 15 | $u^9+u^4+1$ |

这里第三个参数表示符号宽度；不同文献的 RS 记法未必相同。$h=n-k$ 来自计数；$t=h/2$ 的保证将在第 4 章证明，不以“一个错误有两个未知量”作为唯一证明。两组码率分别是 $69/73$ 和 $354/384$，冗余占发送码字的比例分别是 $4/73$ 和 $30/384$。

不同纠错码使用的约束不同，相应的编码和译码算法也不同。下文具体推导 RS 的“域运算 → 编码 → 伴随式 → 最短递推 → 位置与幅值 → 复核”这条链；这些步骤的正确性来自 RS 的约束，不能自动套到所有纠错码上。

| $\operatorname{log}$ | 对数表，将非零域元素值编码映射回整数指数；零没有表项 | 2.3 |
| $\rho_i(u)$ | 多项式除法求逆过程中第 $i$ 个余数；初值为域模和待求逆多项式 | 2.2 |
| $\kappa_i(u)$ | 第 $i$ 步多项式带余除法的商 | 2.2 |
| $U_i(u)$ | 将余数写成域模与待求逆多项式组合时，待求逆多项式前的系数 | 2.2 |
| $W_i(u)$ | 上述组合中，域模多项式前的系数 | 2.2 |
| $i$ | 多项式除法求逆过程的步骤编号 | 2.2 |
| $v(u)$ | 余数变成 1 时的 $U_i$，对域模取余后就是 $a$ 的逆 | 2.2 |
| $z(u)$ | 余数变成 1 时的 $W_i$；与 $v(u)$ 一起构成恒等式 | 2.2 |
| $K$ | 域模去掉最高项 $u^w$ 后的低位编码，用于移位归约 | 2.4 |
| $v$ | 固定的域常量；不与求逆证明中的多项式 $v(u)$ 混用 | 2.4 |
| $M_v$ | 乘固定常量 $v$ 的二进制矩阵 | 2.4 |
| $M_v[i,j]$ | 上述矩阵的一项，表示输入位 $j$ 是否贡献到输出位 $i$ | 2.4 |
| $\operatorname{bit}_i$ | 提取域元素值编码的第 $i$ 个比特，返回 0 或 1 | 2.4 |

**本章结论**　域加法是 XOR，域乘法是无进位多项式乘积再归约；指数表只描述非零元素。常量乘可展开成固定 XOR 网，两个运行时变量相乘则需要通用域乘法。推导：§2.1 → §2.2 → §2.3 → §2.4。

### 2.1 为什么符号加法可以用异或

域是一套加、减、乘、除都能自洽进行的数系：加法和乘法满足交换律、结合律、分配律，有 0 和 1，每个元素有加法逆元，每个非零元素有乘法逆元。乘法逆元是乘回原元素后得到 1 的元素，因此除以非零元素可定义为乘它的逆元。“有限”表示这套数系只有有限个元素。

最小的例子是二元域 $\mathbb F_2=\{0,1\}$：加法、乘法都先按普通整数算，再取模 2。这样 $1+1=0$，$1\cdot1=1$。这个等式也解释了“特征为 2”：两个 1 相加就是 0，而不代表一个符号只有两比特。

多项式是有限个“系数乘变量整数次幂”的和；这里的系数只能取 0 或 1，$u$ 只是区分各比特位置的形式变量，不是额外的输入信号。一个符号的多项式基表示定义为

$$a(u)=\sum_{j=0}^{w-1}a_ju^j,\qquad b(u)=\sum_{j=0}^{w-1}b_ju^j,\qquad a_j,b_j\in\mathbb F_2.$$

这里 $j=0,\ldots,w-1$ 是比特位置，$a_j,b_j$ 是这一位置的比特；其整数值编码分别为 $a=\sum_{j=0}^{w-1}a_j2^j$、$b=\sum_{j=0}^{w-1}b_j2^j$。多项式表示与值编码描述同一个符号，下面会按算术语境使用相应写法。

这些基项 $1,u,\ldots,u^{w-1}$ 每一项对应一个比特位置，用系数选择是否包含该项，称为多项式基表示。例如 `0x2C=00101100`，所以 $a(u)=u^5+u^3+u^2$。同次幂的系数模 2 相加，恰好是比特异或：

$$a(u)+b(u)=\sum_{j=0}^{w-1}(a_j\oplus b_j)u^j.$$

因此域加法和域减法都由 XOR 实现。以后在域中写加号、减号或 $\oplus$，算术效果相同；普通整数的下标运算仍然是普通加减。例如 $n-1-i$ 不需要异或。

<a id="sec-2-2"></a>
### 2.2 乘法为什么必须做多项式归约

多项式的次数记为 $\deg$，是最高非零项的指数；零多项式没有最高非零项，约定其次数为 $-\infty$。带余除法是从被除式最高次项开始，用除式的倍数逐次消去它，直到余数次数低于除式；得到“被除式 = 商 × 除式 + 余数”。这里的系数按模 2 计算。

两个 $w$ 比特符号相乘后，多项式次数可能超过 $w-1$。选择一个次数为 $w$ 的多项式 $p_{\mathrm{fld}}(u)$，只保留相乘后除以它的余数，定义

$$a\otimes b=(a(u)b(u))\bmod p_{\mathrm{fld}}(u).$$

这种“按多项式取余”也叫归约；符号 $\bmod$ 表示取余，不是对值编码做普通整数取模。余数次数低于 $w$，所以结果能存回 $w$ 比特。乘积没有整数乘法的进位，同次幂出现两次会相消。

不可约多项式是不能拆成两个次数都大于零、且都低于自身次数的多项式乘积的非零多项式。若域模可以拆成这样的两因子，它们各自的余数不为零，乘积余数却为零。这种“非零乘非零得到零”的元素称为零因子；有零因子时，某些非零值无法拥有乘法逆元。为了能够除以任意非零符号，我们选不可约的域模。

下面说明不可约为何足够，而不把一个算法名称当作证明。对非零 $a(u)$，因为其次数低于域模，不可约的域模与它没有正次数的共同因子；这种关系叫互素。以下余数 $\rho_i$、商 $\kappa_i$ 以及组合系数 $U_i,W_i$ 都是形式变量 $u$ 的多项式，行文中省略自变量 $(u)$。定义余数序列初值

$$\rho_0=p_{\mathrm{fld}},\qquad\rho_1=a.$$

每步做多项式带余除法，$\kappa_i$ 是商，$\rho_{i+1}$ 是余数：

$$\rho_{i-1}=\kappa_i\rho_i+\rho_{i+1},\qquad\deg\rho_{i+1}<\deg\rho_i.$$

任何同时整除 $\rho_{i-1},\rho_i$ 的因子也整除 $\rho_{i+1}$；反过来也成立，因为可用上式恢复 $\rho_{i-1}$。因此每步保留同一组共同因子。非零余数的次数严格下降，有限步后终止；最后非零余数就是共同因子。互素意味着最后只能是非零常数，在二元系数中就是 1。这个逐次取余过程叫欧几里得算法。

若同时记录每个余数来自原始两多项式的组合，就得到扩展欧几里得算法。“扩展”仅指多保存组合系数，不是另一种取余规则。令

$$\rho_i=U_i a+W_i p_{\mathrm{fld}},$$

初值为 $U_0=0,W_0=1,U_1=1,W_1=0$。在特征 2 中移项仍是加法，将前两条组合式代入余数递推，得到

$$U_{i+1}=U_{i-1}+\kappa_iU_i,\qquad W_{i+1}=W_{i-1}+\kappa_iW_i.$$

所以这一组合关系从初值起逐步保持。余数变成 1 的这一步，将对应组合系数改记为 $v(u):=U_i(u)$、$z(u):=W_i(u)$，便有

$$v(u)a(u)+z(u)p_{\mathrm{fld}}(u)=1.$$

两边对域模取余，第二项为零，于是 $(v\bmod p_{\mathrm{fld}})\otimes a=1$。这就构造出了每个非零符号的逆元。加法和乘法的交换律、结合律及分配律继承自多项式运算，取余只把相差域模倍数的表示合为同一元素；每个元素加自身为零。因此所得数系满足前一节的域要求，称为 $\mathrm{GF}(2^w)$（Galois Field，即有限域），也写成 $\mathbb F_q$，其中 $q=2^w$。

例如 8 比特域模的完整编码是 `0x11D`，包含最高项 $u^8$；去掉该最高位的归约常量是 `0x1D`。二者用途不同，不能互换。把 $u$ 取余所得的域元素定义为 $\alpha:=u\bmod p_{\mathrm{fld}}(u)$，其值编码为 `0x02`；下一节说明为什么它可用于给非零元素编号。

<a id="sec-2-3"></a>
### 2.3 本原元和指数表到底表示什么

本原元是其整数次幂能够遍历域内所有非零元素的一个域元素。这里“遍历”表示从 1 出发反复乘它，每个非零元素都恰好出现一次，然后返回 1。不可约多项式保证域存在，但不自动保证刚选的 $\alpha$ 就是本原元；余数类在这里指对域模取余后相同的所有多项式表示。本篇的两个模多项式还具有本原性：逐次乘 $\alpha$，在第一次返回 1 之前，恰好出现 $q-1$ 个不同非零值。因此可用 $\alpha^0,\ldots,\alpha^{q-2}$ 给所有非零元素编号。

非零符号 $a,b$ 各对应唯一的幂编号，分别记为整数 $A,B\in\{0,\ldots,q-2\}$。因为 $\alpha^{q-1}=1$，普通幂运算规则给出

$$a=\alpha^A,\quad b=\alpha^B,\quad a\otimes b=\alpha^{(A+B)\bmod(q-1)}.$$

若 $a\ne0$，取指数 $-A$ 就得到逆元：$\alpha^A\alpha^{-A}=\alpha^0=1$，所以

$$a^{-1}=\alpha^{(-A)\bmod(q-1)},\qquad a/b=\alpha^{(A-B)\bmod(q-1)}.$$

把整数指数映射成值编码的表叫指数表，反向查询非零值编码的表叫对数表，记为 $\operatorname{exp}(A)=\alpha^A$、$\operatorname{log}(\alpha^A)=A$，其中指数代表元取 $0,\ldots,q-2$。这里的“对数”是幂编号的反查，不是对普通整数值求实数对数。零没有对数，也没有逆元；查表电路必须先处理零。加法不遵守指数相加：$\alpha^1\oplus\alpha^2=\mathtt{0x02}\oplus\mathtt{0x04}=\mathtt{0x06}$，而 $\alpha^3=\mathtt{0x08}$。正确流程是值编码做异或，再在需要时查回指数。

域中满足某个模多项式的根不止一个，本原元也不止一个。本篇选择值编码 `0x02` 是坐标约定；仅知道符号宽度和一个多项式，不能把所有互通约定都推成“唯一”。另一套基、另一种本原元编号可能描述同一套域加法与乘法关系，却产生不同的硬件常数和接口编码。

<a id="sec-2-4"></a>
### 2.4 从归约等式到乘法电路

选择的 $\alpha$ 满足 $p_{\mathrm{fld}}(\alpha)=0$；使多项式求值为零的值称为该多项式的根。8 比特域因此满足这一根等式，把最高次项移到另一侧；特征为 2，移项仍是加法：

$$\alpha^8=\alpha^4+\alpha^3+\alpha^2+1.$$

记域模去掉最高项 $u^w$ 后剩余部分的 $w$ 比特值编码为 $K$；例如 8 比特域的 $K=\mathtt{0x1D}$。输入编码的最高比特为 $a_{w-1}$，已在第 2.1 节的系数展开中定义。乘 $\alpha$ 时，低次项整体左移，只有移位前的最高位可能产生 $\alpha^8$。用上式替换它，得到

$$\alpha\otimes a=((a\ll1)\bmod 2^w)\oplus(a_{w-1}K).$$

这里 $a_{w-1}K$ 的含义是最高位为 1 时选 $K$，否则选 0。8 比特时 $K=\mathtt{0x1D}$；9 比特时由 $\alpha^9=\alpha^4+1$ 得 $K=\mathtt{0x011}$。这是移位加条件 XOR，不能写成普通乘 2 后整数取模。

任意两个符号的乘法也可用“逐位展开”：$b=\sum_jb_j\alpha^j$，由分配律

$$a\otimes b=\bigoplus_{j=0}^{w-1}b_j(a\otimes\alpha^j).$$

各项 $a\otimes\alpha^j$ 可从上面的移位归约递推产生。组合实现会形成 AND 与 XOR 网络；逐位复用实现则用约 $w$ 拍，必须在状态机里等待结果有效。

若一侧是固定常量 $v$，则输入 $a=\sum_ja_j\alpha^j$ 给出

$$v\otimes a=\bigoplus_ja_j(v\otimes\alpha^j),\qquad M_v[i,j]=\operatorname{bit}_i(v\otimes\alpha^j).$$

矩阵在这里就是按输出位 $i$ 为行、输入位 $j$ 为列排列的系数表；$M_v[i,j]=1$ 表示该输入位贡献到该输出位。公式中的 $\operatorname{bit}_i$ 表示取值编码的第 $i$ 比特。因此输出第 $i$ 位是这一行所有标 1 的输入位的 XOR。常量乘可离线展开为固定 XOR 网。后续第 6 章计算定位递推系数时，两侧操作数通常都在运行时变化，必须使用通用域乘法。

寄存器传输级（Register-Transfer Level，简称 RTL）描述寄存器在时钟沿怎样更新，以及寄存器之间怎样计算下一值。上面的逐位算法给出可复用的多拍计算，固定矩阵则给出可组合展开的逻辑网络；第 9 章据此安排实际状态和拍序。

### 3.1 统一多项式方向和编码参数

**约定**　信息符号记为 $D_0,\ldots,D_{k-1}\in\mathbb F_q$，$i$ 是信息位置。取码字层的形式变量 $z$；线路位置 0 先到，并映射到最高次。把信息装入 $M(z)$，把编码根约束装入 $g(z)$，定义

$$M(z)=\sum_{i=0}^{k-1}D_i z^{k-1-i},\qquad g(z)=\prod_{j=1}^{h}(z+\alpha^j).$$

每个因子的最高项系数是 1，所以 $g$ 的最高项系数是 1，次数为 $h$。代入 $z=\alpha^j$，其中一个因子为 $\alpha^j+\alpha^j=0$，因此 $g(\alpha^j)=0$。

根的起始指数 $\beta$ 常称为 FCR（First Consecutive Root，对应第一连续生成根的指数）。这里 FCR 指整数指数，而不是域元素值编码。更一般可取根 $\alpha^\beta,\ldots,\alpha^{\beta+h-1}$，编码常数和第 7.3 节的幅值恢复因子会跟着改变。本篇固定 $\beta=1$ 以减少初学者的下标负担；第 7.3 节补出一般因子。

请分清三个变量：$u$ 用于域元素的比特基表示；$z$ 的系数是域元素，用于信息与码字；后面的 $x$ 用于错误定位与递推。它们都是形式变量，职责不同，不能把 $x$ 的系数数组移位误写成乘域元素 `0x02`。

<a id="sec-3-2"></a>
### 3.2 系统编码为什么在指定点为零

系统编码（systematic encoding）指信息符号在码字中原样保留，再附加校验符号；接收端没有得到另一份原文。下面用多项式带余除法构造这种码字。

先给信息多项式乘 $z^h$，空出低 $h$ 个系数的位置。做带余除法，将商记为 $Q(z)$、余数记为 $P(z)$：

$$M(z)z^h=Q(z)g(z)+P(z),\qquad\deg P<h.$$

定义系统码字

$$c(z):=M(z)z^h+P(z)=\sum_{i=0}^{n-1}c_i z^{n-1-i}.$$

将除法等式代入，因为 $P+P=0$，得到

$$c(z)=Q(z)g(z)+P(z)+P(z)=Q(z)g(z).$$

所以 $c$ 被 $g$ 整除。在每个生成根处

$$c(\alpha^j)=Q(\alpha^j)g(\alpha^j)=0,\qquad j=1,\ldots,h.$$

发送序列为原始 $D_0,\ldots,D_{k-1}$，然后是 $P$ 从高次到低次的 $h$ 个系数。数据没有被替换成少量校验，而是原样发送并附加校验。

零信息会编码成零码字；它是合法码字。一般只能说 $\deg c\le n-1$，信息最高位非零时才等于 $n-1$。商 $Q$ 的系数也不等于信息 $M$ 的系数。

<a id="sec-3-3"></a>
### 3.3 为什么编码只需要 h 级反馈寄存器

反馈寄存器把本拍输入与上一拍的部分状态合成一个反馈量，再用它更新各级寄存器。这里是一个按符号工作的线性反馈移位寄存器（Linear Feedback Shift Register，LFSR）：移位搬运的是整个域符号，抽头运算是常量域乘与 XOR。先推导它该保存什么，再得到反馈式。

前缀是已经处理的开头那部分输入。处理数为 $i$ 时，定义

$$A_i(z):=\sum_{b=0}^{i-1}D_b z^{i-1-b},\qquad A_0(z)=0.$$

其中 $b$ 枚举已处理的信息位置；$i=0$ 时和为空，值为零。追加 $D_i$ 等于已有各项乘 $z$ 再加新的常数项，所以 $A_{i+1}=zA_i+D_i$。我们希望寄存器始终保存

$$R^{(i)}(z):=(A_i(z)z^h)\bmod g(z)=\sum_{j=0}^{h-1}R_j^{(i)}z^j.$$

在推导某一拍时，把旧系数 $R_j^{(i)}$ 简写为 $R_j$，下一拍系数 $R_j^{(i+1)}$ 写作 $R_j^{\mathrm{next}}$；因此每个符号寄存器恰好保存余数的一个升幂系数。生成式也按升幂写成

$$g(z)=z^h+\sum_{j=0}^{h-1}g_jz^j,$$

其中最高项系数为 1 已由第 3.1 节的因子乘积证明。

初始 $A_0=0$，所以寄存器全零。由前缀递推，下一余数为

$$R^{(i+1)}=(zR^{(i)}+D_i z^h)\bmod g.$$

把 $zR$ 写开：最高次项是 $R_{h-1}z^h$，其他项是 $R_{j-1}z^j$。因为 $g\bmod g=0$，特征为 2，得到

$$z^h\bmod g=\sum_{j=0}^{h-1}g_jz^j.$$

所以两个最高次贡献可合并，定义 $f=D_i\oplus R_{h-1}$，逐项取系数得到

$$R_0^{\mathrm{next}}=g_0\otimes f,$$

$$R_j^{\mathrm{next}}=R_{j-1}\oplus(g_j\otimes f),\qquad j=1,\ldots,h-1.$$

这就是反馈寄存器的更新式。上面的余数关系在初值成立，若在第 $i$ 步成立，递推便使它在第 $i+1$ 步成立；这种始终保持的关系称为不变式。处理完 $k$ 个输入后，它给出 $R^{(k)}=Mz^h\bmod g=P$。每个 $g_j$ 固定，因此需要 $h$ 组常量乘 XOR 网和 $h$ 个符号寄存器。

RTL 必须让所有下一值使用同一拍的旧寄存器。若用软件式原地更新且先覆盖 $R_0$，后续 $R_1$ 可能读到新值，数学递推就被改变。非阻塞赋值（右侧读取本拍更新前状态，下一值统一提交）或显式 `next` 数组可以保持旧值语义。

<a id="sec-3-4"></a>
### 3.4 生成系数和截短码为什么可以离线确定

生成多项式的固定系数在反馈寄存器中决定每条反馈支路，因此称为编码抽头。它们只依赖固定的域和根参数，可以在硬件运行前确定。

记已乘入前 $j$ 个根因子的多项式为 $g^{(j)}(z):=\prod_{b=1}^{j}(z+\alpha^b)$；$j=0$ 时空乘积为 1。第 $j$ 步乘因子前后的系数关系写成

$$g^{(j-1)}(z)=\sum_{\ell=0}^{j-1}a_\ell z^\ell,\qquad g^{(j)}(z)=(z+\alpha^j)g^{(j-1)}(z)=\sum_{\ell=0}^{j}b_\ell z^\ell.$$

这里 $\ell$ 是系数次数。当前项 $a_\ell z^\ell$ 会分别贡献 $a_\ell z^{\ell+1}$ 和 $(a_\ell\alpha^j)z^\ell$，因此新系数由这两路相加：

$$b_\ell=(a_\ell\otimes\alpha^j)\oplus a_{\ell-1}.$$

不存在的系数按零处理。连续做 $h$ 次，就得到所有编码抽头。8 比特、$h=4$ 的升幂结果为

$$[g_0,g_1,g_2,g_3,g_4]=[\mathtt{74},\mathtt{E7},\mathtt{D8},\mathtt{1E},\mathtt{01}].$$

这些数可以在编译前生成，不需要运行时展开大多项式。

截短码（shortened code）是先把全长码的某些信息位置固定为零，再不发送这些已知位置而得到的较短码。本篇只删除前导零信息位置。

从全长码中固定并删除前导零信息符号，剩下的多项式低次部分没有改变，前导零在编码反馈寄存器中也不产生状态变化。因此仍用同一个 $g$、同一个域和同样的校验数。删除前导零不等于在任意位置丢弃数据；后者会改变位置对应关系。

全长码长记为 $n_{\mathrm{full}}=q-1$，删除的前导零信息位置数记为 $\ell_{\mathrm{short}}=n_{\mathrm{full}}-n$。两组参数分别由全长 $(255,251)$ 删除 182 个前导零信息位置，和全长 $(511,481)$ 删除 127 个前导零信息位置得到。算例与脚本固定这一位置约定。

### 4.1 伴随式只包含错误的原因

伴随式（syndrome）是接收多项式在编码约束指定的根处的求值结果，用来检查收到的串是否满足码约束。它是可由接收数据直接算出的域元素，不是一份原始信息，也不是某个错误位置的值。下面推导它如何消掉未知信息。

按线路位置定义 $r(z)=\sum_{i=0}^{n-1}r_i z^{n-1-i}$；发送码字同样按降幂表示。错误位置为 $p_a$，次数为 $d_a=n-1-p_a$，位置编码为 $X_a=\alpha^{d_a}$，幅值为 $E_a=r_{p_a}+c_{p_a}$。其中 $a=1,\ldots,\nu$ 是错误清单序号，不是线路位置。接收多项式因此为 $r=c+e$。只有错误位置有非零差值，所以

$$e(z)=\sum_{a=1}^{\nu}E_a z^{d_a}.$$

接收端在生成根处求值，定义 $S_j:=r(\alpha^j)\in\mathbb F_q$，$j=1,\ldots,h$ 是生成根编号。第 3 章已经证明合法码字在这些点为零，故

$$S_j=c(\alpha^j)+e(\alpha^j)=0+e(\alpha^j).$$

将错误多项式代入，再利用普通幂规则 $(\alpha^j)^{d_a}=(\alpha^{d_a})^j$，得到

$$S_j=\sum_{a=1}^{\nu}E_aX_a^j,\qquad j=1,\ldots,h.$$

接收端只计算左边，不知道右边的 $E_a,X_a$。右边用于解释和证明，不能当作接收端已经掌握的输入。

$E_a$ 是发送与接收的 XOR 差值，不是接收符号本身。若发送值是 `0x8D`、错误幅值是 `0x95`，接收值为 `0x18`；译码器要计算的改变量是 `0x95`。

<a id="sec-4-2"></a>
### 4.2 Horner 递推为什么能边收边算

Horner 法（霍纳法，也叫秦九韶法）是把多项式从高次到低次改写成嵌套乘加的求值方法。它解决的问题是：如何求 $r(\xi)$，却不用先分别生成并保存 $\xi,\xi^2,\ldots$ 的所有幂？这里 $\xi$ 是任意选定的域元素求值点，不是新的多项式形式变量。

先看四个接收符号组成的多项式。按分配律逐层提出 $\xi$，有

$$r(\xi)=r_0\xi^3+r_1\xi^2+r_2\xi+r_3,$$

$$r(\xi)=\xi(r_0\xi^2+r_1\xi+r_2)+r_3,$$

$$r(\xi)=\xi\bigl(\xi(r_0\xi+r_1)+r_2\bigr)+r_3.$$

写成算法，就是先取状态 0，再按线路顺序读 $r_0,r_1,r_2,r_3$，每次执行“旧状态乘 $\xi$，再加本次符号”。比如第一步为 $0\cdot\xi+r_0=r_0$，第二步为 $r_0\xi+r_1$，第三步为 $(r_0\xi+r_1)\xi+r_2$，第四步得到上式；每步只需一次乘法和一次加法。

求第 $j$ 个伴随式时，选定 $\xi=\alpha^j$。它在该支路内固定。令 $V_j^{(i)}$ 表示已经接受前 $i$ 个接收符号后的状态，$i$ 为数量，下一输入的位置也为 $i$；$j=1,\ldots,h$ 是伴随式支路编号。由嵌套求值过程得到

$$V_j^{(0)}=0,\qquad V_j^{(i+1)}=V_j^{(i)}\otimes\alpha^j\oplus r_i.$$

下面证明这个过程对任意码长成立。基例 $i=0$ 时尚无输入，和为空，值为 0。假设处理 $i$ 个符号后的状态为

$$V_j^{(i)}=\sum_{b=0}^{i-1}r_b(\alpha^j)^{i-1-b},$$

其中 $b$ 枚举已接收前缀内的线路位置。把它代入下一状态式，逐项乘开：

$$V_j^{(i+1)}=\left(\sum_{b=0}^{i-1}r_b(\alpha^j)^{i-1-b}\right)\alpha^j+r_i,$$

$$V_j^{(i+1)}=\sum_{b=0}^{i-1}r_b(\alpha^j)^{i-b}+r_i(\alpha^j)^0,$$

$$V_j^{(i+1)}=\sum_{b=0}^{i}r_b(\alpha^j)^{i-b}.$$

这正是把假设式中的 $i$ 换成 $i+1$，因此逐步归纳到 $i=n$ 得

$$V_j^{(n)}=\sum_{b=0}^{n-1}r_b(\alpha^j)^{n-1-b}=r(\alpha^j)=S_j.$$

所以 Horner 并非另一套纠错规则，而是与直接展开式完全等价的求值安排。硬件可用 $h$ 条并行支路，每条保存一个 $w$ 比特状态并用固定 $\alpha^j$ 的常量乘网络计算下一值。接收一个符号就更新一次；输入暂停时保持状态。第 9.2 节再说明最后一个输入为何必须用下一值冻结伴随式。

<a id="sec-4-3"></a>
### 4.3 为什么 h 个根确实保证 h 加一的最小距离

一个码字的重量是其中非零符号的个数。两码字的符号距离，等于它们逐位置相加所得差码字的重量；因为相同符号相加为零，不同符号相加非零。合法码字都被 $g$ 整除，它们的和也被 $g$ 整除，所以仍是合法码字。故要给最小距离求下界，只需给非零合法码字的重量求下界。

反设某个非零合法码字只有 $\mu\le h$ 个非零位置。用 $a=1,\ldots,\mu$ 枚举这些位置，非零符号值记为 $v_a$；若这一项位于线路位置 $i$，就定义其位置域编码 $Y_a:=\alpha^{n-1-i}$，与第 4.1 节的位置换算一致。它在前 $\mu$ 个生成根处为零，所以

$$\sum_{a=1}^{\mu}v_aY_a^j=0,\qquad j=1,\ldots,\mu.$$

这是关于未知非零符号值的一组线性方程：“线性”表示未知值只乘已知系数并相加，没有未知值之间相乘。下面通过消元证明它们迫使每个 $v_a$ 为零；消元是对已有等式乘系数后相加，消掉不想保留的未知量。

先看 $\mu=2$。两式为 $v_1Y_1+v_2Y_2=0$ 和 $v_1Y_1^2+v_2Y_2^2=0$。第一式乘 $Y_2$ 后加第二式，$v_2$ 的两项相消，剩下

$$v_1Y_1(Y_1+Y_2)=0.$$

不同位置有不同的非零 $Y$，所以系数非零，可除去它，得到 $v_1=0$。反过来第一式乘 $Y_1$ 后加第二式，得到 $v_2=0$。这就与“两个非零符号”的假设矛盾。

一般 $\mu$ 时，为了只留下第 $a$ 个位置，构造辅助多项式

$$F_a(y)=y\prod_{b\ne a}(y+Y_b)=\sum_{j=1}^{\mu}A_j^{(a)}y^j.$$

当 $\mu=1$ 时乘积没有因子，空乘积约定为 1，因此 $F_a(y)=y$，同样适用。这里 $y$ 只是辅助形式变量；$A_j^{(a)}$ 是展开后 $y^j$ 的已知系数，不是新未知量。因为有前导因子 $y$，没有常数项，次数为 $\mu$，所需系数恰好对应已知的第 1 至 $\mu$ 条方程。对每条方程乘相应的 $A_j^{(a)}$，再相加并交换有限求和顺序：

$$0=\sum_{j=1}^{\mu}A_j^{(a)}\sum_{b=1}^{\mu}v_bY_b^j,$$

$$0=\sum_{b=1}^{\mu}v_b\left(\sum_{j=1}^{\mu}A_j^{(a)}Y_b^j\right)=\sum_{b=1}^{\mu}v_bF_a(Y_b).$$

若 $b\ne a$，$F_a(Y_b)$ 含有 $Y_b+Y_b=0$ 的因子，因此这些项全部消失；唯一留下的项为

$$v_aF_a(Y_a)=v_aY_a\prod_{b\ne a}(Y_a+Y_b)=0.$$

所有 $Y_a$ 非零。线路位置对应的次数处于 $0,\ldots,n-1$，而 $n\le q-1$、非零幂周期为 $q-1$，所以不同位置的 $Y$ 互不相同，所有 $Y_a+Y_b$ 也非零。域中非零元素的乘积非零，因此可除去完整系数，得到 $v_a=0$。对每个 $a$ 都可构造上述权重，所有非零符号都被迫为零，矛盾。故任意非零合法码字至少有 $h+1$ 个非零符号，即 $d_{\min}\ge h+1$。

再证明上界。系统编码有 $q^k$ 个不同码字，因为前 $k$ 个符号就是信息。假设最小距离为 $d_{\min}$，删除任意 $d_{\min}-1$ 个位置之后，不同码字仍不同：若剩余部分相同，它们原来最多只差被删的那些位置，与距离定义冲突。剩余 $n-d_{\min}+1$ 个位置每处只有 $q$ 种取值，因此最多容纳 $q^{n-d_{\min}+1}$ 种序列，得到

$$q^k\le q^{n-d_{\min}+1}.$$

由于 $q>1$，幂函数随指数增加，所以 $k\le n-d_{\min}+1$，移项得

$$d_{\min}\le n-k+1=h+1.$$

与下界合并，得到

$$d_{\min}=h+1=2t+1.$$

代入第 1.2 节的距离条件，最多 $t$ 个未知位置符号错误便有唯一的发送码字。这一证明只需按给定的已知系数将方程相加消元。

<a id="sec-4-4"></a>
### 4.4 一个伴随式为零不代表没有错误

两处错误时 $S_1=E_1X_1+E_2X_2$。任取非零 $E_1$，令 $E_2=E_1X_1/X_2$，则两项相同，在特征 2 中相消，所以 $S_1=0$。这说明不能从“存在错误”直接推出 $S_1\ne0$。

如果所有 $h$ 个伴随式为零，接收串满足码约束，是一个合法码字。若已知错误数 $\nu\le h$，第 4.3 节对错误多项式的同样论证说明非零错误不可能全部伴随式为零，因而在该条件下可判无错误。

如果完全不限制错误数，信道可以把一个合法码字改成另一个合法码字，所有伴随式仍是零。因此“合法”与“原始码字”必须分开理解。

### 5.1 从位置编码构造递推系数

取定位层的形式变量 $x$，系数仍属于 $\mathbb F_q$。定位多项式是把全部错误位置收进其根的一个多项式；求出它再求根，就能把位置问题拆成两步。为了让根对应位置编码的倒数，我们定义

$$\Lambda(x)=\prod_{a=1}^{\nu}(1+X_ax)=\sum_{\ell=0}^{\nu}\Lambda_\ell x^\ell,\qquad\Lambda_0=1.$$

代入 $x=X_a^{-1}$，第 $a$ 个因子为零，所以 $\Lambda(X_a^{-1})=0$。错误位置对应的是这个多项式的根的倒数。

将根等式乘 $E_aX_a^j$，对全部错误求和，逐项展开：

$$0=\sum_aE_aX_a^j\sum_{\ell=0}^{\nu}\Lambda_\ell X_a^{-\ell}.$$

有限求和交换次序后

$$0=\sum_{\ell=0}^{\nu}\Lambda_\ell\sum_aE_aX_a^{j-\ell}=\sum_{\ell=0}^{\nu}\Lambda_\ell S_{j-\ell},\qquad j\ge\nu+1.$$

把递推系数按次数组成的多项式称为连接多项式；上面证明真实定位多项式可以提供一组这样的系数，实际译码还要从已知序列求出它。常数项取 1 是归一化约定：若常数项非零，将全部系数除以它，所有递推等式只被整体缩放，零残差不变。

最后范围保证用到的伴随式下标全部为正。把 $\ell=0$ 的 $S_j$ 移到另一边，得到 $\nu$ 阶递推：当前伴随式由前 $\nu$ 个伴随式的固定域线性组合产生。

真实错误的位置现在被藏进 $\Lambda_1,\ldots,\Lambda_\nu$。这些系数未知，但在递推方程里以线性方式出现，这比直接反解未知指数位置更容易。

<a id="sec-5-2"></a>
### 5.2 有限几何和怎样导出关键方程

先把已知的 $h$ 个伴随式装进一个多项式，称为伴随式多项式：

$$\Sigma_h(x)=\sum_{j=1}^{h}S_jx^{j-1}.$$

第一个伴随式放常数项，是为了让乘积的系数下标与递推对齐；第 6.2 节会逐项核对。以下的模 $x^h$ 表示只保留次数 $0,\ldots,h-1$ 的系数，因为每个更高次项都能被 $x^h$ 整除。

有限几何和是把同一比值的连续整数次幂相加。在这里为 $G_a(x)=\sum_{m=0}^{h-1}(X_ax)^m$，$m$ 是项的次数，只有 $h$ 项。把第 4.1 节的伴随式表达代入 $\Sigma_h$，交换有限求和：

$$\Sigma_h(x)=\sum_aE_aX_a\sum_{m=0}^{h-1}(X_ax)^m=\sum_aE_aX_aG_a(x).$$

不直接引用无限级数。先乘开有限和：$(1+X_ax)G_a$ 中间各项都出现两次而相消，只剩头项和尾项：

$$(1+X_ax)G_a=1+(X_ax)^h\equiv1\pmod{x^h}.$$

因此在只保留前 $h$ 个系数的意义下，$G_a$ 是 $1+X_ax$ 的逆。把上式乘以 $\Lambda$，第 $a$ 个分母因子被消去，得到

$$\Lambda\Sigma_h\equiv\sum_aE_aX_a\prod_{b\ne a}(1+X_bx)\pmod{x^h}.$$

定义右边为 $\Omega$，称为错误求值多项式；它的系数由位置与幅值共同决定，后面会在定位根处用它恢复幅值。这个等式把未知的定位多项式、已知的伴随式多项式和低次分子联系起来，称为关键方程；“关键”说明它是译码需要求解的约束，不是额外已知的信息。于是得到

$$\Lambda(x)\Sigma_h(x)\equiv\Omega(x)\pmod{x^h},\qquad\deg\Omega<\nu.$$

每一项最多有 $\nu-1$ 个一次因子，所以分子次数小于 $\nu$；如果最高系数相消，次数还会更低，不能把它一律写成等于 $\nu-1$。

把已经推得的求值多项式按升幂记录为

$$\Omega(x)=\sum_{j=0}^{\nu-1}\Omega_jx^j.$$

这里 $j$ 是次数；$\nu=0$ 时没有错误，空和取零。这个展开式定义后续卷积计算和寄存器中的 $\Omega_j$，不把它与从 1 起编号的伴随式 $S_j$ 混用。

这些是用真实 $X_a,E_a$ 写出的理论形式。卷积在这里就是多项式乘法的系数计算：某一输出次数由所有“次数相加等于它”的系数对乘积相加得到。“截断”指按模 $x^h$ 丢掉次数不小于 $h$ 的项，不是对系数值作整数取模。实际译码先从已知 $S_j$ 求 $\Lambda$，再做截断卷积 $\Omega=(\Lambda\Sigma_h)\bmod x^h$，从未要求先知道错误位置。

<a id="sec-5-3"></a>
### 5.3 为什么有足够伴随式时最短解就是错误定位多项式

本节假设 $\nu\le t$，因此已知伴随式数满足 $h=2t\ge2\nu$。先证明真实分子与分母没有共同因子。真实 $\Lambda$ 完全分解为互不相同的一次因子。在 $x=X_a^{-1}$ 处，$\Omega$ 除第 $a$ 项外全部含零因子，留下

$$\Omega(X_a^{-1})=E_aX_a\prod_{b\ne a}(1+X_b/X_a).$$

幅值非零、位置编码非零且互异，因此这个值非零。$\Lambda$ 的任何一次因子都不整除 $\Omega$，两者互素。这也证明了 $\nu>0$ 时 $\Omega$ 非零，而不需要错误地假设 $S_1\ne0$。

现在取非负整数候选长度 $\ell\le\nu$，把候选递推系数写成

$$C(x):=\sum_{i=0}^{\ell}C_i x^i,\qquad C_0=1.$$

下标 $i$ 是次数，允许最高系数为零，所以只要求 $\deg C\le\ell$。若候选满足全部所需递推 $\sum_{i=0}^{\ell}C_iS_{j-i}=0$（$j=\ell+1,\ldots,h$），则乘积 $C\Sigma_h$ 在次数 $\ell,\ldots,h-1$ 的系数全为零。将剩余低次部分定义为

$$A(x):=(C(x)\Sigma_h(x))\bmod x^h,\qquad\deg A<\ell,$$

便得到 $C\Sigma_h\equiv A\pmod{x^h}$。候选和真实关键方程分别乘 $\Lambda$ 和 $C$，中间的 $C\Lambda\Sigma_h$ 相消，所以

$$D(x)=C(x)\Omega(x)+\Lambda(x)A(x)\equiv0\pmod{x^h}.$$

左边次数至多 $\ell+\nu-1$，并且

$$\ell+\nu-1\le2\nu-1<h.$$

一个次数小于 $h$ 的多项式若被 $x^h$ 整除，只能是零。因此 $C\Omega=\Lambda A$。由于 $\Lambda$ 与 $\Omega$ 互素，$\Lambda$ 必须整除 $C$：可从每个一次因子逐个检查得到这个结论。

这迫使 $\deg C\ge\nu$。结合 $\deg C\le\ell\le\nu$，只能有 $\ell=\nu$，且 $C$ 是 $\Lambda$ 的常数倍。二者常数项都为 1，这个倍数只能是 1。因此最短候选唯一，恰是 $\Lambda$。

真实 $\Lambda$ 已经提供长度 $\nu$ 的可行解，所以最短长度既不大于也不小于 $\nu$。对 $\nu=0$ 单独看：全部伴随式为零，长度 0、$C=1$ 即可。

这段证明把“方程数够”变成了严格的充分条件。它不声称每一个任意候选长度的伴随式矩阵都可逆；某些短前缀会退化，下一章的最短递推算法正是要处理这些情况。

### 6.1 先区分递推长度和多项式次数

Berlekamp–Massey 算法（简称 BM）是从一段已知序列逐步求出最短线性递推的算法。在本文中，序列是已测得的伴随式；它输出连接多项式 $C$ 和递推长度 $L$。连接多项式是把递推系数按升幂存放的多项式，不是新增加的编码约束。所谓“最短”，是使用最少的前序值和初始条件，仍能生成已经看到的序列。下面先严格定义长度，再逐步证明更新规则。

已知前 $N$ 个伴随式 $S_1,\ldots,S_N$，$N$ 是前缀长度，迭代时从 1 增加到 $h$。对非负整数候选长度 $L\le N$，定义承载递推系数的多项式

$$C(x):=\sum_{i=0}^{L}C_i x^i,\qquad C_0=1,\qquad C_i\in\mathbb F_q.$$

一次展开同时确定 $C$ 与系数数组的关系：下标 $i$ 是次数，尾部系数允许为零，因此 $\deg C\le L$。长度 $L$ 的含义是：前 $L$ 个符号作为初始条件，从第 $L+1$ 个开始必须满足

$$S_j+\sum_{i=1}^{L}C_iS_{j-i}=0,\qquad j=L+1,\ldots,N.$$

**定义**　在所有满足这些条件的 $(C,L)$ 中，最小的 $L$ 称为这段有限前缀的线性复杂度（linear complexity），记为 $\operatorname{LC}(N)$。这里的复杂度是递推所需长度，不是硬件面积或运行拍数。$L=N$ 时约束集为空，因此一定存在可行长度；初始空序列用 $L=0,C=1$。

不能把 $L$ 总写成 $\deg C$。举例：前缀 $S_1=1,S_2=0$ 可用长度 1、$C_1=0$ 的递推生成：第一个值作为初态，后续预测为零。但多项式 $C=1$ 的次数为 0。长度 0 要求所有值都为零，生成不了第一个 1，所以最小长度确实是 1。

随着前缀增加，最小长度不会减小：一个能生成更长前缀的递推，也能生成它的较短前缀。只在完整、可纠的 RS 伴随式上，第 5.3 节才保证最终 $L=\deg\Lambda=\nu$。

<a id="sec-6-2"></a>
### 6.2 残差为什么既能检查方程又能随多项式移位

我们需要一个统一的检查量：给定任意一组系数，判断它们在第 $j$ 条递推方程上是否产生零残差。取非负整数 $m$，定义任意测试多项式

$$Q(x):=\sum_{i=0}^{m}Q_i x^i,\qquad Q_i\in\mathbb F_q.$$

这里 $i$ 是系数次数，$m$ 是本次展开的最高存储次数，允许尾部系数为零；它不代表最短递推长度 $L$。这个 $Q(x)$ 用来测试递推，与第 3.2 节带余除法的商 $Q(z)$ 是不同对象。

使用已知伴随式 $S_1,\ldots,S_h$；非正下标补零，即 $S_j:=0$ 对 $j\le0$。补零只是计算边界约定，不表示真的测得 $S_0=r(1)=0$。定义第 $j$ 条方程的残差

$$\Delta_j(Q):=\sum_{i=0}^{m}Q_iS_{j-i}.$$

上式在涉及的正伴随式下标不超过 $h$ 时使用；本章的轮号和方程编号满足这一条件。若 $Q_0=1$，它展开为 $S_j+\sum_{i=1}^{m}Q_iS_{j-i}$，即实际值与这组系数预测值的差。将当前状态 $C$ 代入，并取 $j=N$，本轮残差定义为

$$\delta_N:=\Delta_N(C)=S_N+\sum_{i=1}^{L}C_iS_{N-i}.$$

所以 $\delta_N=0$ 只说明本轮这条方程成立；它不表示所有后续方程也成立。

再联系第 5.2 节已定义的 $\Sigma_h(x)=\sum_{b=1}^{h}S_bx^{b-1}$。乘积的 $x^{j-1}$ 项只能来自次数满足 $i+(b-1)=j-1$ 的系数对，因此 $b=j-i$。对 $1\le j\le h$，不存在的非正下标补零后有

$$[x^{j-1}](Q\Sigma_h)=\sum_{i=0}^{m}Q_iS_{j-i}=\Delta_j(Q).$$

其中 $[x^{j-1}]$ 表示取出该次幂的系数。于是残差检查与关键方程的对应系数检查相同。

为了说明这个检查量如何组合，再取 $R(x):=\sum_{i=0}^{m}R_i x^i$，以及任意域元素 $a\in\mathbb F_q$。两个多项式的展开长度可以用尾部补零统一。分配律给出

$$\Delta_j(Q+R)=\sum_{i=0}^{m}(Q_i+R_i)S_{j-i}=\sum_{i=0}^{m}Q_iS_{j-i}+\sum_{i=0}^{m}R_iS_{j-i}=\Delta_j(Q)+\Delta_j(R),$$

$$\Delta_j(aQ)=\sum_{i=0}^{m}(aQ_i)S_{j-i}=a\sum_{i=0}^{m}Q_iS_{j-i}=a\Delta_j(Q).$$

最后取非负整数移位数 $s$。乘以 $x^s$ 只把系数移到更高次数，展开为 $x^sQ(x)=\sum_{i=0}^{m}Q_i x^{i+s}$；它的第 $i+s$ 次系数仍是 $Q_i$。代入残差定义，得到

$$\Delta_j(x^sQ)=\sum_{i=0}^{m}Q_iS_{j-(i+s)}=\sum_{i=0}^{m}Q_iS_{(j-s)-i}=\Delta_{j-s}(Q).$$

这个“系数搬移导致残差下标搬移”的等式，是 BM 能复用历史多项式的核心；它不涉及有限域中的幂乘电路。

<a id="sec-6-3"></a>
### 6.3 历史快照为什么正好能修复当前残差

先讨论已有真实历史快照的情况。把最近一次长度增长的轮号记为 $H\ge1$；该轮更新前的连接多项式和旧递推长度分别保存为 $B,L_B$，即

$$B(x)=\sum_{i=0}^{L_B}B_i x^i,\qquad B_0=1,\qquad b:=\Delta_H(B)\ne0.$$

这里的 $b$ 保存该次增长时的非零残差，系数 $B_i$ 与它来自同一历史状态。快照对当时已有的约束 $j=L_B+1,\ldots,H-1$ 残差为零；在第 $H$ 条上残差为 $b$。当前轮残差简写为 $\delta:=\delta_N=\Delta_N(C)$。我们将同时维护账目关系

$$H=L_B+L,\qquad s=N-H.$$

这两条关系的初始化和更新在第 6.5 节逐项核对，不是额外输入。

若当前残差非零，需要给 $C$ 加一个修正项。为了让历史残差落到当前第 $N$ 条，平移性质要求 $N-s=H$，也就是 $s=N-H$。再把历史残差缩放到 $\delta$，比例必须是 $\delta/b$，记为 $q_{\mathrm{BM}}:=\delta/b$；它是域元素，区别于域大小 $q$。所以构造

$$C^{\mathrm{new}}=C+\frac{\delta}{b}x^sB.$$

在当前条上直接计算：

$$\Delta_N(C^{\mathrm{new}})=\delta+\frac{\delta}{b}\Delta_{N-s}(B)=\delta+\frac{\delta}{b}b=0.$$

只消掉当前残差还不够，必须看历史方程。设目标新长度 $L'=\max(L,N-L)$。对任何 $j=L'+1,\ldots,N-1$，因为 $j>L$，旧 $C$ 的残差为零；同时

$$j-s\ge L'+1-(N-H)\ge(N-L)+1-N+H=L_B+1,$$

$$j-s\le N-1-(N-H)=H-1.$$

所以对应的 $B$ 残差也落在它已经满足的区间里，仍为零。修正不会破坏新长度需要保留的任何历史方程。

次数方面，$\deg C\le L$，$\deg B\le L_B$，所以

$$\deg(x^sB)\le s+L_B=N-H+L_B=N-L,$$

$$\deg C^{\mathrm{new}}\le\max(L,N-L)=L'.$$

由此构造出长度至多 $L'$ 的可行解。下一节证明再短就不可能。

<a id="sec-6-4"></a>
### 6.4 长度增长的下界证明

本节在当前残差 $\delta\ne0$ 时证明长度下界。把当前已知前缀装入

$$F(x):=\sum_{j=1}^{N}S_jx^{j-1}=\Sigma_h(x)\bmod x^N.$$

任取能满足前 $N$ 个值所需递推的新候选，其长度为非负整数 $M$，系数写成

$$D(x):=\sum_{i=0}^{M}D_i x^i,\qquad D_0=1,\qquad\deg D\le M.$$

这里 $M$ 是递推长度，区别于第 3 章的信息多项式 $M(z)$。候选必须满足 $\Delta_j(D)=0$ 对 $j=M+1,\ldots,N$。我们要证明任何这样的新候选都满足 $M\ge N-L$。反设 $M<N-L$，即整数关系 $L+M\le N-1$。

旧 $C$ 已经满足第 $L+1$ 条至第 $N-1$ 条方程；第 $N$ 条的残差为 $\delta$。按第 6.2 节的系数关系，$CF$ 的 $x^{j-1}$ 系数是 $\Delta_j(C)$。把它的低 $L$ 项定义为

$$A_C(x):=\sum_{j=1}^{L}\Delta_j(C)x^{j-1}.$$

若 $L=0$，这个和为空，取零。次数 $L,\ldots,N-2$ 的系数由旧递推约束为零，最后的 $x^{N-1}$ 系数是 $\delta$。因此将 $CF$ 按次数分开得到：

$$CF\equiv A_C+\delta x^{N-1}\pmod{x^N},\qquad\deg A_C<L.$$

候选 $D$ 同样满足所需方程。把低 $M$ 项定义为

$$A_D(x):=\sum_{j=1}^{M}\Delta_j(D)x^{j-1}.$$

若 $M=0$，空和取零；其余直到次数 $N-1$ 的系数都由候选约束为零，所以

$$DF\equiv A_D\pmod{x^N},\qquad\deg A_D<M.$$

由乘法交换和结合律，$D(CF)=C(DF)$。把两边上述形式代入：

$$DA_C+\delta x^{N-1}D\equiv CA_D\pmod{x^N}.$$

只看 $x^{N-1}$ 系数。两项 $DA_C$ 与 $CA_D$ 的次数至多 $L+M-1\le N-2$，不可能贡献这一系数。由于 $D(0)=1$，$\delta x^{N-1}D$ 的该系数正是 $\delta$。于是等式要求 $\delta=0$，与本轮条件矛盾。

因此 $M\ge N-L$。再结合最短长度不会减小，任何新候选还满足 $M\ge L$，所以

$$M\ge\max(L,N-L).$$

上一节已构造出这个长度的可行解，上界和下界相遇，得到

$$L^{\mathrm{new}}=\max(L,N-L)\qquad(\delta\ne0).$$

若 $\delta=0$，旧解继续可用，单调性又不允许更短，故长度保持。证明至此无需用随机测试替代，也不需要预先知道错误个数。

<a id="sec-6-5"></a>
### 6.5 初值和分支如何维持全部关系

哨兵是算法初始化时人为放置的占位状态，用来让尚无真实历史时也能执行统一的分支；它不表示真的观测过第 0 轮残差。初始化为 $C=B=1$，$L=L_B=H=0$，$b=1$，第 1 轮 $s=1$。这样 $H=L_B+L$、$s=N-H$ 都成立；$b=1$ 只负责保证可除，不能声称它是实际的 $\Delta_0(B)$。

若最开始若干伴随式全零，$L=0$ 保持。第一次非零值出现在轮 $N$ 时，$H$ 仍为零，$s=N$，构造式给出 $C^{\mathrm{new}}=1+\delta x^N$，新长度为 $N$。此时要求检查的区间 $j=N+1,\ldots,N$ 为空，所以不需要让第 $N$ 条残差归零。第 6.3 节“当前残差归零”的计算只对 $H\ge1$ 的真实快照成立。

一般轮的完整算法如下。在非零残差分支进入更新前，定义临时副本 $T(x):=C(x)$，即 $T_i=C_i$；旧长度同样记为 $L_{\mathrm{old}}:=L$。所有计算使用这些更新前状态，数组按升幂保存，越界系数为零。

```text
C = B = [1, 0, ..., 0]
L = 0; b = 1; s = 1
for N = 1 .. h:
    delta = S[N] XOR sum_{i=1..L}(C[i] * S[N-i])
    if delta == 0:
        s = s + 1
    else:
        T = C                         # 保存旧值
        q_BM = delta / b               # 有限域除法
        C[i] = T[i] XOR q_BM * B[i-s]  # 并行的数学下一值
        if 2*L < N:                   # 必须读取旧 L
            B = T
            b = delta
            L = N - L
            s = 1
        else:
            s = s + 1
```

其中非正下标的 `S` 和越界的 `B` 都返回零；`*`、`/` 均为域算术。若 $2L<N$，有 $N-L>L$，需要增长，存档旧长度 $L_B\leftarrow L_{\mathrm{old}}$ 和当前轮 $H\leftarrow N$。于是

$$L_B+L^{\mathrm{new}}=L_{\mathrm{old}}+(N-L_{\mathrm{old}})=N=H.$$

下一轮 $s=(N+1)-H=1$。不增长或残差为零时，$H,L,L_B$ 都不变，$N$ 增一，所以 $s$ 也增一。账目关系始终保持。

每次真实存档都由非零残差触发，因此存下来的 $b$ 不会为零。$s\ge1$ 又让修正项不含常数项，归一化版本的 $C_0$ 始终为 1。

从空前缀开始，用第 6.3 节的可行构造和第 6.4 节的最短长度下界逐轮归纳，得到 BM 每轮都保持最短递推。最后 $N=h\ge2\nu$ 时，第 5.3 节使最终结果等于真实 $\Lambda$。

`delta == 0` 只证明某一条方程成立，不是通用的停止条件。朴素实现必须处理完全部 $h$ 条伴随式；若设计另一种经过完整证明的提前终止机制，则需单独给出判据和验证，不能只看单轮残差。

<a id="sec-6-6"></a>
### 6.6 免除法更新为何保持相同的结果

归一化是把多项式整体乘一个非零常数，使常数项为 1；它不改变多项式的根。前面的更新每个非零残差轮都计算比例 $\delta/b$，因此需要求逆。免除法更新（inversionless update）把这一比例式两边乘上非零比例因子，保留整体缩放的多项式，避免在每轮先做除法。先定义存储状态 $\widehat C=\gamma C$、$\widehat B=\eta B$，其中 $\gamma,\eta\ne0$；残差对多项式线性，所以 $\widehat\delta=\gamma\delta$、$\widehat b=\eta b$。

不要先除以 $b$，改用存储状态计算

$$\widehat C^{\mathrm{new}}=\widehat b\widehat C+\widehat\delta x^s\widehat B.$$

把缩放定义逐项代入：

$$\widehat C^{\mathrm{new}}=\eta b\gamma C+\gamma\delta x^s\eta B=\gamma\eta b\left(C+\frac{\delta}{b}x^sB\right).$$

括号里恰好是归一化 BM 的新状态，所以二者只差一个非零整体因子。增长轮存下缩放旧 $C$ 和它实际算出的残差，关系仍自洽；非增长轮保持旧快照；残差零轮可以直接保持 $\widehat C$。长度判断因此相同。

缩放后 $\widehat C_0$ 不再固定为 1，但非零乘法不会改变根。完成 BM 后若需要标准化，可让所有系数除以 $\widehat C_0$；也可直接进入第 7 章的求根与幅值恢复。在正确译码的最终状态中，$C=\Lambda$，所以缩放状态也记为 $\widehat\Lambda:=\widehat C=\gamma\Lambda$。用它定义缩放后的求值多项式

$$\widehat\Omega(x):=(\widehat\Lambda(x)\Sigma_h(x))\bmod x^h=\gamma\Omega(x).$$

末项来自乘积与取余对系数的线性关系。第 7.2 节将定义形式导数并证明其线性，因而还有 $\widehat\Lambda'=\gamma\Lambda'$；该节幅值公式的分子分母缩放因子便相消。

免除法减少了 BM 中的求逆需求，却仍需要通用有限域乘法，第 7.2 节的幅值恢复阶段也仍需求逆或等价的除法结构。本篇不把“免除法 BM”写成“整个译码器完全没有除法”。

### 7.1 Chien 搜索为什么只需要逐位置推进

Chien 搜索（钱氏搜索）是按码块的所有可能位置逐个求定位多项式的值，找出零值所对应位置的求根方法。它不需要先把多项式解析分解；本篇再把逐位置求值改写成可用常量乘网络推进的状态。

沿用 BM 得到的最终定位多项式，其系数关系为 $\Lambda(x)=\sum_{j=0}^{L}\Lambda_jx^j$，$L$ 在此表示最终定位次数，$j$ 是系数次数。第 5.1 节已经证明 $\Lambda(X_a^{-1})=0$。扫描零基位置 $i=0,\ldots,n-1$ 时，定义对应次数及测试点

$$d:=n-1-i,\qquad z_i:=\alpha^{-d}=\alpha^{-(n-1-i)}.$$

因此只要检查

$$\Lambda(\alpha^{-(n-1-i)})=0.$$

从位置 $i$ 到 $i+1$，次数 $d$ 减一，所以测试点满足

$$z_{i+1}=\alpha^{-(d-1)}=\alpha z_i.$$

为了保存求值的各项，定义 $T_j^{(i)}:=\Lambda_jz_i^j$，$j=0,\ldots,L$；上标 $i$ 是扫描位置，下标 $j$ 是系数次数。下一位置由 $z_{i+1}=\alpha z_i$ 得到，因此这些寄存器可递推：

$$T_j^{(i+1)}=\Lambda_j(\alpha z_i)^j=\alpha^jT_j^{(i)}.$$

每拍把全部 $T_j$ 异或相加，即得当前 $\Lambda(z_i)$。每条支路的乘数 $\alpha^j$ 固定，可用常量 XOR 网。启动时初始化 $T_j^{(0)}=\Lambda_j\alpha^{-j(n-1)}$，然后先判断本位置，再推进到下一位置。

只需扫描实际发送的 $n$ 个位置。截短码没有发送的前导零位置不属于可修正范围。最终必须有 $L$ 个互异命中；不足可能意味着某些根不在码块中，或者候选多项式不适合本次译码。

<a id="sec-7-2"></a>
### 7.2 Forney 求幅值的完整推导

Forney 公式（福尼公式）是在错误位置已经找到之后，利用错误求值多项式和定位多项式的形式导数恢复错误幅值的方法。“幅值”是一个有限域元素，表示应异或回接收符号的差值，不是实数大小，也不是接收符号本身。

本节沿用主约定：生成根从 $\alpha^1$ 开始，即 $\beta=1$，伴随式数为 $h=2t$。其中 $t$ 是保证可纠正的错误符号数。先假设本次实际错误数 $\nu$ 满足 $1\le\nu\le t$，且 BM 已完整处理全部 $h$ 个伴随式；第 5.3 节证明此时最终长度 $L=\nu$，BM 输出就是真实定位多项式。无错误的 $\nu=0$ 分支直接输出，不执行本节求逆。

**（1）先把已知量与待求量接起来**

第 $a$ 个错误的零基线路位置记为 $p_a$，错误序号 $a=1,\ldots,\nu$；位置已由 Chien 搜索找到。码长为 $n$，位置域编码和定位根分别是

$$X_a:=\alpha^{n-1-p_a},\qquad z_a:=X_a^{-1}=\alpha^{-(n-1-p_a)}.$$

未知错误幅值为域元素 $E_a$。接收符号 $r_{p_a}$ 与原发送符号 $c_{p_a}$ 满足 $r_{p_a}=c_{p_a}+E_a$。译码器知道 $r_{p_a}$ 和 $p_a$，但不知道 $c_{p_a}$ 或 $E_a$，因此不能靠两者相减直接得到幅值。

已知综合征（前文称“伴随式”）由第 4.1 节给出：

$$S_j=r(\alpha^j)=\sum_{a=1}^{\nu}E_aX_a^j,\qquad j=1,\ldots,h.$$

这里 $j$ 是综合征编号。每个 $S_j$ 混合了所有错误的贡献。Forney 要把其中一个错误的幅值单独取出来，而不再求解一整组幅值联立方程。

定位多项式与综合征多项式按升幂写成

$$\Lambda(x)=\sum_{j=0}^{L}\Lambda_jx^j=\prod_{a=1}^{\nu}(1+X_ax),\qquad \Lambda_0=1,$$

$$\Sigma_h(x):=\sum_{j=1}^{h}S_jx^{j-1}=S_1+S_2x+\cdots+S_hx^{h-1}.$$

第二式把综合征编号减一映射为次数，因此常数项是 $S_1$，不能放成 $S_0$。

**（2）先算出错误求值多项式，不能直接在根处计算未截断乘积**

沿用第 5.2 节的定义，错误求值多项式为

$$\Omega(x):=(\Lambda(x)\Sigma_h(x))\bmod x^h
=\sum_{j=0}^{h-1}\Omega_jx^j.$$

“模 $x^h$”指只保留次数 $0$ 至 $h-1$ 的系数。将两多项式逐项相乘，输出次数 $j$ 必须由定位次数 $\ell$ 与综合征次数 $j-\ell$ 配对；$\ell$ 是非负整数次数下标。后者对应综合征 $S_{j-\ell+1}$，所以

$$\Omega_j=\sum_{\ell=0}^{\min(j,L)}\Lambda_\ell S_{j-\ell+1},\qquad j=0,\ldots,h-1.$$

展开前四项，便可直接对照 RTL 的乘法与异或：

$$\Omega_0=S_1,$$

$$\Omega_1=S_2+\Lambda_1S_1,$$

$$\Omega_2=S_3+\Lambda_1S_2+\Lambda_2S_1,$$

$$\Omega_3=S_4+\Lambda_1S_3+\Lambda_2S_2+\Lambda_3S_1.$$

这些展开式中，次数超过 $L$ 的 $\Lambda_j$ 视为零。正确结果满足 $\deg\Omega<L$；故计算到 $h-1$ 后，应检查 $\Omega_L,\ldots,\Omega_{h-1}$ 全零，再仅保存低 $L$ 项用于求值。

不能把 $\Omega(z_a)$ 改写成 $\Lambda(z_a)\Sigma_h(z_a)$：后者因为 $\Lambda(z_a)=0$ 而恒为零，求不出幅值。原因是“先丢弃高次项，再代入非零根”与“直接代入整个乘积”是两个不同操作。第 5.2 节证明的模 $x^h$ 关系，只保证低次系数相同，不保证两个多项式在非零点的值相同。

**（3）为什么 $\Omega$ 在一个根处只留下一个错误**

先重接第 5.2 节的推导。把综合征表达式代入 $\Sigma_h$，并定义有限几何和

$$G_a(x):=\sum_{m=0}^{h-1}(X_ax)^m,$$

其中 $m$ 是从 $0$ 到 $h-1$ 的整数次数，得到

$$\Sigma_h(x)=\sum_{a=1}^{\nu}E_aX_aG_a(x).$$

乘开 $(1+X_ax)G_a$，中间项重复两次而相消，只剩头尾：

$$(1+X_ax)G_a(x)=1+(X_ax)^h\equiv1\pmod{x^h}.$$

由于 $\Lambda$ 含有因子 $1+X_ax$，将上式用于乘积 $\Lambda\Sigma_h$，再丢掉次数不小于 $h$ 的项，得到

$$\Omega(x)=\sum_{a=1}^{\nu}E_aX_a\prod_{b\ne a}(1+X_bx).$$

这里 $b$ 是另一个错误的序号，$b\ne a$ 表示乘积不包含第 $a$ 个位置。每项最多有 $\nu-1$ 个一次因子，所以右侧次数小于 $\nu\le h$，截断后的相等关系可以写成上面的普通多项式等式。

现在固定一个目标错误 $a$，代入它的根 $z_a=X_a^{-1}$。求和中属于其他错误的项，都还含有目标因子

$$1+X_az_a=1+1=0,$$

因此这些项全部消失。属于目标错误的那一项，恰好没有这个因子，留下

$$\boxed{\Omega(z_a)=E_aX_a\prod_{b\ne a}(1+X_b/X_a).}$$

以两个错误为例，把求和完整写开：

$$\Omega(x)=E_1X_1(1+X_2x)+E_2X_2(1+X_1x).$$

在 $z_1=X_1^{-1}$ 处，第二项乘上 $1+X_1z_1=0$，只剩 $E_1X_1(1+X_2/X_1)$；在 $z_2=X_2^{-1}$ 处，第一项消失，只剩 $E_2X_2(1+X_1/X_2)$。所以根处已经把不同错误分开，但目标幅值还乘着一个位置因子。

**（4）形式导数怎样得到完全相同的位置因子**

形式导数是对多项式系数执行的代数规则，定义为

$$\Lambda'(x):=\sum_{j=1}^{L}j\Lambda_jx^{j-1}.$$

整数 $j$ 表示把系数加到自身 $j$ 次；在特征为 2 的域中，偶数次相加为零，奇数次相加保留原系数。因此

$$\Lambda'(x)=\Lambda_1+\Lambda_3x^2+\Lambda_5x^4+\cdots.$$

它不是实数微积分中的数值微分。RTL 只需选择原来的奇数次系数，并把次数减一。偶数次项消失，但保留下来的项仍位于次数 $0,2,4,\ldots$，不能把它们压成连续次数 $0,1,2,\ldots$ 后仍用 $z_a$ 求值。

要在因子形式上求导，需要乘积规则。任取域系数多项式 $A(x)=\sum_\ell a_\ell x^\ell$、$B(x)=\sum_j b_jx^j$；本段的 $B$ 是待求导的第二个多项式，不是第 6 章的历史快照。每对项相乘为 $a_\ell b_jx^{\ell+j}$，求导后系数是 $(\ell+j)a_\ell b_j$。把它拆成 $\ell a_\ell b_j+ja_\ell b_j$，分别对应对第一项、第二项求导，因此 $(AB)'=A'B+AB'$。

对 $\Lambda=\prod_a(1+X_ax)$ 反复应用这条规则：每次只对一个因子求导，其余因子保留；一次因子的导数为 $X_a$。于是

$$\Lambda'(x)=\sum_{a=1}^{\nu}X_a\prod_{b\ne a}(1+X_bx).$$

代入 $z_a$，其他错误对应的项也都含目标零因子而消失，得到

$$\boxed{\Lambda'(z_a)=X_a\prod_{b\ne a}(1+X_b/X_a).}$$

这与 $\Omega(z_a)$ 中乘在 $E_a$ 后面的因子完全相同。

**（5）为什么能除，以及相除后为什么就是幅值**

位置编码 $X_a$ 是 $\alpha$ 的幂，非零。不同错误占据不同符号位置，且这些位置的编码互异，所以 $X_b\ne X_a$。因此 $X_b/X_a\ne1$，从而

$$1+X_b/X_a\ne0.$$

分母是若干非零域元素的乘积，故 $\Lambda'(z_a)\ne0$，可以求逆。将前两式相除，共同的位置因子约掉：

$$\boxed{E_a=\frac{\Omega(z_a)}{\Lambda'(z_a)}\qquad(\beta=1).}$$

这就是本文约定下的 Forney 公式。它恢复每个错误幅值，既不用知道原发送符号，也不用把所有幅值重新联立求解。若候选根处导数为零，说明当前候选不满足互异简单根的前提，基础译码器应拒绝，不能对零求逆。

**（6）把公式拆成可执行的有限域运算**

对第 $a$ 个根，定义分子、分母和分母逆元，均为域元素：

$$U_a:=\Omega(z_a),\qquad V_a:=\Lambda'(z_a),\qquad I_a:=V_a^{-1}\quad(V_a\ne0).$$

于是幅值计算就是 $E_a=U_aI_a$。两个多项式求值可按第 4.2 节已解释的 Horner 法，从最高次到最低次反复执行“累加值乘 $z_a$，再异或当前系数”；导数数组先按上面的奇偶规则生成。详细的多拍操作数冻结、求逆等待和 RAM 写回见 §9.5。

若使用第 6.6 节的整体缩放输出，设同一个非零域常量为 $\gamma$，则分子和导数都被乘以 $\gamma$；形式导数对常数倍逐项保留这个系数，所以

$$\frac{\gamma\Omega(z_a)}{(\gamma\Lambda)'(z_a)}
=\frac{\gamma\Omega(z_a)}{\gamma\Lambda'(z_a)}
=E_a.$$

需要一致缩放；若只有定位多项式缩放而求值多项式未同步重算，两个 $\gamma$ 就无法抵消。

**（7）为什么异或写回就能纠正符号**

接收关系是 $r_{p_a}=c_{p_a}+E_a$。加上恢复的同一个幅值：

$$r_{p_a}+E_a=c_{p_a}+E_a+E_a=c_{p_a}.$$

因此位置 $p_a$ 执行一次异或写回即可，其他位置保持原值。完整数值链见 §8.4，可复现脚本为同目录 `forney_trace_check.py`，运行 `python forney_trace_check.py`；脚本逐项检查卷积、根处消项、导数乘积、Horner、缩放抵消、幅值和修正后综合征。

### 7.3 第一个根不是一时为什么多出一个因子

生成根起始指数 $\beta$ 是第 3.1 节的整数参数，也称 FCR。此时第 $j$ 个综合征为

$$S_j^{(\beta)}:=r(\alpha^{\beta+j-1})
=\sum_{a=1}^{\nu}E_aX_a^{\beta+j-1},\qquad j=1,\ldots,h.$$

第二个等号来自把接收多项式写成合法码字与错误之和；码字在这些生成根处为零，每个错误项则贡献 $E_a(\alpha^{\beta+j-1})^{n-1-p_a}=E_aX_a^{\beta+j-1}$。

定义相应的综合征多项式并逐项代入：

$$\Sigma_h^{(\beta)}(x):=\sum_{j=1}^{h}S_j^{(\beta)}x^{j-1}
=\sum_{a=1}^{\nu}E_aX_a^\beta G_a(x).$$

这里的有限几何和 $G_a$ 已在 §7.2 定义。利用那里证明的 $(1+X_ax)G_a\equiv1\pmod{x^h}$，定位多项式乘入后，每项消去一个因子，得到

$$\Omega_\beta(x):=(\Lambda\Sigma_h^{(\beta)})\bmod x^h
=\sum_{a=1}^{\nu}E_aX_a^\beta\prod_{b\ne a}(1+X_bx).$$

在根 $z_a=X_a^{-1}$ 处，其他项含零因子而消失，所以

$$\Omega_\beta(z_a)=E_aX_a^\beta\prod_{b\ne a}(1+X_b/X_a).$$

定位多项式和它的导数只依赖位置，不随 $\beta$ 改变。用 §7.2 的分母表达式相除，得到

$$\frac{\Omega_\beta(z_a)}{\Lambda'(z_a)}
=\frac{E_aX_a^\beta\prod_{b\ne a}(1+X_b/X_a)}
{X_a\prod_{b\ne a}(1+X_b/X_a)}
=E_aX_a^{\beta-1}.$$

再乘 $X_a^{1-\beta}$ 才是错误幅值，因此本文特征为 2 的域中，通用公式为

$$\boxed{E_a=X_a^{1-\beta}\frac{\Omega_\beta(z_a)}{\Lambda'(z_a)}
=z_a^{\beta-1}\frac{\Omega_\beta(z_a)}{\Lambda'(z_a)}.}$$

最后一个等号来自 $X_a=z_a^{-1}$。$\beta=1$ 时附加因子为 1；$\beta=0$ 时需要乘 $X_a=z_a^{-1}$；$\beta=2$ 时需要乘 $z_a$。负指数对应非零域元素的逆元，不是整数负幂运算。

因此从其他资料抄幅值公式前，必须核对生成根起点、综合征多项式的次数起点和定位根使用 $X_a$ 还是 $X_a^{-1}$。本文的一般公式由这些约定逐步推得，不能单独增删一个位置因子。补充脚本 `forney_trace_check.py` 覆盖 $\beta=0,1,2$；原参考模型的 `decode` 仍只实现 $\beta=1$，补充验证不改变这个接口限制。

### 8.1 固定输入和全部约定

本例固定 $n=73,k=69,h=4,t=2,w=8$，沿用域模 `0x11D`、本原元 $\alpha=\mathtt{02}$ 和根起始指数 $\beta=1$。为避免依赖原笔记的随机数生成方式，本例采用明确的信息输入 $D_0,\ldots,D_{68}$：前四个符号是 `2C 74 11 E7`，后 65 个信息符号全零。生成系数是升幂 `74 E7 D8 1E 01`。

先观察前四拍，所有数都是域元素的值编码：

| 信息位置 | 输入 | 反馈 $f$ | 更新后寄存器从高次到低次 |
|---:|---|---|---|
| 0 | `2C` | `2C` | `6F CB 61 6C` |
| 1 | `74` | `1B` | `E4 9B E5 08` |
| 2 | `11` | `F5` | `8F 75 B2 58` |
| 3 | `E7` | `68` | `B1 3A FD ED` |

第一拍的最低抽头乘法可手算：`74` 表示 $u^6+u^5+u^4+u^2$，`2C` 表示 $u^5+u^3+u^2$。逐项相乘并消去偶数次出现的项，剩下

$$u^{11}+u^{10}+u^7+u^6+u^5+u^4.$$

由 $u^8=u^4+u^3+u^2+1$，两边分别乘 $u^2$、$u^3$ 得

$$u^{10}=u^6+u^5+u^4+u^2,\qquad u^{11}=u^7+u^6+u^5+u^3.$$

逐项代回、再次相消，剩下 $u^6+u^5+u^3+u^2$，值为 `6C`。因此第一拍 $R_0=\mathtt{6C}$。其他抽头按相同的乘法定义或已核验的指数表求值。

表中四拍之后的寄存器还不是 RS(73,69) 的最终校验；必须继续处理剩下 65 个零输入，因为这些拍仍推动余数移位与归约。全部 69 拍结束后，最终校验为

$$P(z)=\sum_{j=0}^{3}P_jz^j,\qquad[P_3,P_2,P_1,P_0]=[\mathtt{A8},\mathtt{24},\mathtt{68},\mathtt{B6}].$$

若只将那四个信息符号作为一个独立的四信息符号教学码块，则校验才是 `B1 3A FD ED`。两种长度不能混在一条码字里。

### 8.2 由两个错误计算伴随式

本例发送序列为 $c=(D_0,\ldots,D_{68},P_3,P_2,P_1,P_0)$。在位置 $p_1=32,p_2=67$ 分别注入幅值 $E_1=\mathtt{95},E_2=\mathtt{61}$，得到接收序列 $r$；只有这两个位置执行 $r_{p_a}=c_{p_a}\oplus E_a$，其余位置 $r_i=c_i$。这两个位置的原值都为零，接收值恰好等于错误幅值；这只是输入构造的结果，一般情况不能这样认定。位置与域编码为

$$d_1=40,\quad X_1=\alpha^{40}=\mathtt{6A},\qquad d_2=5,\quad X_2=\alpha^5=\mathtt{20}.$$

指数表给出 $E_1=\alpha^{184}$、$E_2=\alpha^{66}$。按 $S_j=E_1X_1^j+E_2X_2^j$ 逐项计算：

| $j$ | 第一个错误的贡献 | 第二个错误的贡献 | XOR 后的 $S_j$ |
|---:|---|---|---|
| 1 | $\alpha^{184+40}=\alpha^{224}$ | $\alpha^{66+5}=\alpha^{71}$ | `AE` $=\alpha^{190}$ |
| 2 | $\alpha^{264}=\alpha^9$ | $\alpha^{76}$ | `24` $=\alpha^{225}$ |
| 3 | $\alpha^{304}=\alpha^{49}$ | $\alpha^{81}$ | `6B` $=\alpha^{84}$ |
| 4 | $\alpha^{344}=\alpha^{89}$ | $\alpha^{86}$ | `50` $=\alpha^{54}$ |

指数乘法先相加，再模 255；求和则把两项查成值编码后 XOR。接收端从整个 $r$ 的 Horner 求值得到同一组 $S$，并没有使用错误清单。

### 8.3 BM 四轮的系数怎样变化

初值 $C=B=[01]$，$L=0,b=01,s=1$。每轮账目如下：

| $N$ | 轮开始 $L,s,b$ | 残差 $\delta_N$ | 比例 $q_{\mathrm{BM}}$ | 分支 | 更新后 $C$ |
|---:|---|---|---|---|---|
| 1 | `0,1,01` | `AE` | `AE` | 增长至 1 | `01 AE` |
| 2 | `1,1,AE` | `17` | `32` | 长度保持 | `01 9C` |
| 3 | `1,2,AE` | `4B` | `FA` | 增长至 2 | `01 9C FA` |
| 4 | `2,1,4B` | `3A` | `D6` | 长度保持 | `01 4A C1` |

**第 1 轮**　$\delta_1=S_1=\mathtt{AE}$。首次非零，无历史约束，修正 $C=1+\mathtt{AE}x$，长度从 0 变为 1。存 $B=1,b=\mathtt{AE}$，下一轮 $s=1$。

**第 2 轮**　此时 $C_1=\alpha^{190}$，所以

$$\delta_2=S_2+C_1S_1=\alpha^{225}+\alpha^{190+190}=\alpha^{225}+\alpha^{125}=\mathtt{17}=\alpha^{129}.$$

比例为 $\alpha^{129-190}=\alpha^{194}=\mathtt{32}$。修正只落在一次项，值编码直接异或：`AE XOR 32 = 9C`。

更新为 $C=1+\mathtt{9C}x$，其中 `9C` $=\alpha^{35}$。长度不变，历史 $B,b$ 不变，$s$ 增至 2。

**第 3 轮**　$\delta_3=\alpha^{84}+\alpha^{35+225}=\alpha^{84}+\alpha^5=\mathtt{4B}=\alpha^{179}$。比例 $\alpha^{179-190}=\alpha^{244}=\mathtt{FA}$。当前 $s=2$、$B=1$，修正落在二次项，因此 $C=1+\mathtt{9C}x+\mathtt{FA}x^2$。旧长度为 1，$2L=2<3$，新长度为 $3-1=2$；存档更新前的 $B=1+\mathtt{9C}x$ 和 $b=\mathtt{4B}$，$s$ 回到 1。

**第 4 轮**　残差为

$$\delta_4=\alpha^{54}+\alpha^{35+84}+\alpha^{244+225}=\alpha^{54}+\alpha^{119}+\alpha^{214}=\mathtt{3A}=\alpha^9.$$

比例是 $\alpha^{9-179}=\alpha^{85}=\mathtt{D6}$。修正项为 $\alpha^{85}x(1+\alpha^{35}x)$，所以两个系数分别是 $\alpha^{85}$ 和 $\alpha^{120}$。逐项 XOR 后

$$\Lambda(x)=1+\mathtt{4A}x+\mathtt{C1}x^2=1+\alpha^{37}x+\alpha^{45}x^2.$$

四轮完成，得到长度 2 的最终定位多项式。用造例者已知的位置验证：$(1+\mathtt{6A}x)(1+\mathtt{20}x)$ 的一次系数是 `6A XOR 20 = 4A`，二次系数是 $\alpha^{40+5}=\alpha^{45}=\mathtt{C1}$，与译码器结果吻合。

<a id="sec-8-4"></a>
### 8.4 位置和幅值的完整计算

先做卷积，逐个系数为

$$\Omega_0=S_1=\mathtt{AE},\qquad\Omega_1=S_2+\Lambda_1S_1=\mathtt{B4},$$

$$\Omega_2=S_3+\Lambda_1S_2+\Lambda_2S_1=0,$$

$$\Omega_3=S_4+\Lambda_1S_3+\Lambda_2S_2=0.$$

因此 $\Omega(x)=\mathtt{AE}+\mathtt{B4}x$。高两项为零，符合次数小于 2 的要求。

Chien 检出两个根 $z_1=\alpha^{215}$、$z_2=\alpha^{250}$。以第一个根为例，Horner 求值：$\alpha^{45}z_1=\alpha^5$；与一次系数 $\alpha^{37}$ 相加得到 $\alpha^{40}$；再乘 $z_1$ 得 $\alpha^{255}=1$；最后加常数 1 得零。第二个根按同一求值式得到零。

根是位置编码的逆元，故次数分别是 $255-215=40$、$255-250=5$；位置分别为 $72-40=32$、$72-5=67$。


下面把 Forney 的卷积、求值、求逆和幅值乘法全部展开。所有数是域元素的十六进制值编码，乘除法在模 `0x11D` 的 $GF(2^8)$ 中进行，不是普通整数运算。脚本与自检方式：在本输出目录运行 `python forney_trace_check.py`，其 `check_case` 对下表逐项卷积、两处 Horner、导数与幅值设置断言，并独立用错误因子乘积核对。

| 输出次数 | 卷积中的各个域乘积值 | XOR 结果 |
|---:|---|---|
| 0 | `AE` | `AE` |
| 1 | `24`、`4A * AE = 90` | `24 XOR 90 = B4` |
| 2 | `6B`、`4A * 24 = 80`、`C1 * AE = EB` | `6B XOR 80 XOR EB = 00` |
| 3 | `50`、`4A * 6B = 76`、`C1 * 24 = 26` | `50 XOR 76 XOR 26 = 00` |

两个根的值编码为 $z_1=\alpha^{215}=\mathtt{EF}$、$z_2=\alpha^{250}=\mathtt{6C}$。分子按 $\Omega(z_a)=\mathtt{AE}+\mathtt{B4}z_a$ 计算；设 $U_a=\Omega(z_a)$，则两次 Horner 的步骤是先装入最高次系数 `B4`，再乘根、异或常数项 `AE`：

$$U_1=\mathtt{AE}+\mathtt{B4}\cdot\mathtt{EF}
=\mathtt{AE}\oplus\mathtt{EB}=\mathtt{45},$$

$$U_2=\mathtt{AE}+\mathtt{B4}\cdot\mathtt{6C}
=\mathtt{AE}\oplus\mathtt{26}=\mathtt{88}.$$

定位多项式为 $\Lambda(x)=1+\mathtt{4A}x+\mathtt{C1}x^2$。常数项导数为零，一次项留下 `4A`，二次项因整数系数 $2=0$ 消失，所以

$$\Lambda'(x)=\mathtt{4A}=\alpha^{37}.$$

令 $V_a=\Lambda'(z_a)$，本例它是常数，所以 $V_1=V_2=\mathtt{4A}$。按非零幂求逆规则，$\mathtt{4A}^{-1}=\alpha^{-37}=\alpha^{218}=\mathtt{2B}$。分子 `45` 的指数为 221，`88` 的指数为 103；幅值除法转为指数相减：

$$E_1=U_1/V_1=\alpha^{221-37}=\alpha^{184}=\mathtt{95},$$

$$E_2=U_2/V_2=\alpha^{103-37}=\alpha^{66}=\mathtt{61}.$$

| 线路位置 | 位置编码 $X_a$ | 定位根 $z_a$ | 分子 $U_a$ | 分母 $V_a$ | 分母逆元 | 恢复幅值 $E_a$ |
|---:|---|---|---|---|---|---|
| 32 | `6A` | `EF` | `45` | `4A` | `2B` | `45 * 2B = 95` |
| 67 | `20` | `6C` | `88` | `4A` | `2B` | `88 * 2B = 61` |

本例导数是常数，所以两个位置共用同一个分母；这是最终次数为 2、特征为 2 的结果。若最终次数为 3，导数变为 $\Lambda_1+\Lambda_3x^2$，必须分别在各根处求值，不能把常数分母优化直接搬过去。

在位置 32、67 分别 XOR 这些值，恢复原码字；重算全部四个伴随式得到零。这里还额外比较了参考模型中已知的发送码字，才能直接验证“确实恢复了原文”。实际接收电路没有这份发送码字。

<a id="sec-8-5"></a>
### 8.5 用两元消元核对 BM 并理解特殊前缀

假设最终长度为 2，把待求的定位多项式写作 $\Lambda(x)=1+\lambda_1x+\lambda_2x^2$；这一步同时定义消元用的系数 $\lambda_1,\lambda_2$。将第 3、4 条递推写开：

$$\lambda_1S_2+\lambda_2S_1=S_3,\qquad\lambda_1S_3+\lambda_2S_2=S_4.$$

第一式乘 $S_2$，第二式乘 $S_1$，相加后两项 $\lambda_2S_1S_2$ 相消，得到

$$\lambda_1(S_2^2+S_1S_3)=S_3S_2+S_4S_1.$$

另将第一式乘 $S_3$、第二式乘 $S_2$，相加消去 $\lambda_1$，得到

$$\lambda_2(S_1S_3+S_2^2)=S_3^2+S_4S_2.$$

因此定义 $D_{\mathrm{det}}=S_2^2+S_1S_3$、$N_1=S_3S_2+S_4S_1$、$N_2=S_3^2+S_4S_2$。代入本例：$D_{\mathrm{det}}=\mathtt{64}\oplus\mathtt{5A}=\mathtt{3E}\ne0$，$N_1=\mathtt{AA}$，$N_2=\mathtt{73}$。除法给出 $\lambda_1=\mathtt{4A}$、$\lambda_2=\mathtt{C1}$，与 BM 相同。

这条消元路径用于学习和交叉核验；主 RTL 流程按第 6 章的递推算法逐轮计算定位系数。未知错误数时，也不能未经检查就固定假设长度为 2。

脚本还构造了同位置的两种特殊错误：幅值为 $1,\alpha^{35}$ 时，$S_1=0$，BM 在后续轮才增长；幅值都为 1 时，第 2 轮残差为零，但后面仍要继续。这两个例子分别说明“首伴随式为零”和“中间残差为零”都不是整体无错误或已经完成译码的证据。

### 9.1 接口和状态存储先确定哪些条件

RAM（Random-Access Memory，随机访问存储器）在这里指可按位置读写的码字缓存；它与符号寄存器都用于保存状态，但同步 RAM 的读数据往往晚于地址发出。握手指生产者给出有效数据、消费者同时声明可接收，二者同拍为真才发生一次传输；否则相关状态保持。

选择一套便于验证的基础架构：输入一次接受一个符号，完整码块先缓存，再做译码，复核完成后才向下游提交数据。这样未来位置的错误不会要求撤回已经输出的数据。高吞吐设计可以在此基础上改成多码块流水（不同阶段同时处理不同码块），但必须保留每块的边界与状态。

建议接口包括 `in_valid/in_ready/in_symbol`、码块开始结束信息，以及 `out_valid/out_ready/out_symbol`、块状态。码长固定时，内部还要检查开始、结束和接受符号数是否一致。若上游丢了一个符号却没有通知，下游位置全部可能错位，已超出本文的替换错误模型。

把本拍真正接受输入的事件记为 `accept := in_valid && in_ready`；码字缓存写为 `cw_ram[i]`，$i$ 是线路位置。`status` 保存本块的处理状态与失败原因。基础存储如下：

| 对象 | 大小或范围 | 用途 |
|---|---|---|
| 码字 RAM | $n\times w$ 比特 | 缓存、修改和复核 |
| 伴随式寄存器 | $h\times w$ 比特 | BM 和卷积的已知输入 |
| $C,B,T$ 系数数组 | 保守各 $(h+1)\times w$ 比特 | 迭代、历史快照、串行更新旧值 |
| 求值系数 | 至多 $h\times w$ 比特 | 保存截断卷积 |
| 错误记录 | 至多 $t$ 个位置和 $t$ 个幅值 | 定位后修正 |
| $L,N,s$ | 范围覆盖 $0$ 至 $h+1$ | 控制与下标边界 |

保守配置能处理任意输入并在出口报失败。若每轮检测新长度一旦超过 $t$ 就中止该块，因为最小长度单调不减，可将系数数组裁到 $t+1$，但必须在写入任何高次系数前先做越界判断。不能先截掉高次再假装算法得到了合法低次结果。

接收位置至少需 $\lceil\log_2 n\rceil$ 位；BM 计数器需覆盖 $h+1$，可用 $\lceil\log_2(h+2)\rceil$ 位；比较 `2*L` 时必须先扩位，不能让左移溢出。下标 `i-s` 应先判 `i>=s`，再计算无符号差。

<a id="sec-9-2"></a>
### 9.2 接收和伴随式状态怎样对齐最后一拍

沿用第 4.2 节的状态，处理了 $i$ 个符号时把 $V_j^{(i)}$ 简写为 $V_j$，计入当前输入后的状态记为 $V_j^{\mathrm{next}}$，所以

$$V_j^{\mathrm{next}}:=V_j\otimes\alpha^j\oplus r_i.$$

片段中的 `synd_acc[j]` 保存 $V_j$，`synd[j]` 保存接收完成后冻结的 $S_j$，`pos=i`，`ALPHA_J[j]` 对应 $\alpha^j$；宏参数 `H=h`、`N_CODE=n`。码块开始时清空所有 $V_j$。每次 `accept`，将符号写入 `cw_ram[i]`，并更新全部累加器。最后一个位置 $i=n-1$ 被接受时，BM 需要的是包含这个输入后的 $V_j^{\mathrm{next}}$，不是同一拍非阻塞赋值前的旧 $V_j$。

```systemverilog
if (accept) begin
  cw_ram[pos] <= in_symbol;
  for (int j = 1; j <= H; j++) begin
    synd_acc[j] <= gf_const_mul(synd_acc[j], ALPHA_J[j]) ^ in_symbol;
    if (pos == N_CODE-1)
      synd[j] <= gf_const_mul(synd_acc[j], ALPHA_J[j]) ^ in_symbol;
  end
end
```

这里 `gf_const_mul` 表示第 2.4 节定义的常量域乘网络。该片段只说明最后拍取值，不是一份带全部复位与握手的完整模块。

如果全部冻结后的伴随式为零，可走无修正输出路径；其含义仍是“接收码字满足约束”。若任一非零，进入 BM。输入暂停时，RAM 地址和全部伴随式状态一并暂停。

<a id="sec-9-3"></a>
### 9.3 一个可以按资源调整的 BM 多周期状态机

当前连接系数、历史系数、临时副本和控制量沿用第 6 章的 $C,B,T,L,s,b,N$。增长条件写为 `grow = (delta != 0) && (2*L < N)`，其中 `delta` 对应 $\delta$，条件读取旧 $L$。记通用乘法器从接受操作数到返回有效结果的延迟为 $\ell_{\mathrm{mul}}$ 拍，调度必须等待相应结果。

ROM（Read-Only Memory，只读存储器）在这里是预先保存非零域元素逆元的查找表。多周期状态机按当前状态选择本拍操作，将一次算法迭代拆成多拍，并在每项结果有效后推进。采用一个可复用的通用域乘法器和一个逆元 ROM，可以按以下顺序实现归一化 BM：

1. `D_INIT`：将残差累加器置为 $S_N$，下标置 1，保留当前旧 $L$。
2. `D_ACC`：依次计算 $C_jS_{N-j}$，有效结果到达时 XOR 累加；只处理 $1\le j\le\min(L,N-1)$。所有这些项只使用未更新的 $C$。
3. 残差为零时直接进入 `COMMIT`，使 $s$ 增一。否则锁存残差和增长条件，保存旧 $C$ 为 $T$。
4. `Q_WAIT`：查 $b^{-1}$ 并计算 $q_{\mathrm{BM}}=\delta b^{-1}$，等待结果有效。$b=0$ 必须作为内部故障处理，不能查一个约定的“零的逆”。
5. `C_UPDATE`：逐个系数写下一值 $T_j\oplus q_{\mathrm{BM}}B_{j-s}$；$j<s$ 时移位项为零。只读旧 $B$。
6. `COMMIT`：若增长，将 $B\leftarrow T,b\leftarrow\delta,L\leftarrow N-L_{\mathrm{old}},s\leftarrow1$；否则只使 $s$ 增一。然后轮号增加，或在第 $h$ 轮完成后离开。

串行写 $C$ 时需要旧快照；如果系数并行写，可以利用所有非阻塞赋值都读旧值的语义省去某些物理快照寄存器。增长时存入 $B$ 的必须是更新前的 $C$。

第 6 章的移位修正、历史保留和长度最短性证明逐项对应这六步。将并行的数学更新拆成多拍不会改变结果，前提是所有操作数被冻结且提交顺序一致。

采用免除法版本时，把比例状态改成两组乘积 $\widehat b\widehat C_j$、$\widehat\delta\widehat B_{j-s}$；历史保存、增长条件和零残差分支仍按第 6.6 节处理。不能一半系数读归一化状态，另一半读缩放状态。

一次 BM 迭代“两拍完成”只有在足够多的乘法器、足够快的求逆及组合路径都满足时才成立。共享单乘法器需要逐项计算残差和修正系数，这些计算分布在多个状态拍中。因此本篇给出数据依赖，不把两拍作为与资源无关的定理。

<a id="sec-9-4"></a>
### 9.4 卷积和 Chien 如何调度

BM 出口先检查 $L\le t$。若保守算法遇到 $L>t$，无法保证本次结果在可纠半径内，基础译码器直接报失败。还要检查 $C_0\ne0$，以及最终实际次数是否等于 $L$；有效可纠输入的正确结果会通过。

卷积系数由次数配对直接得到：第 $j$ 项要求定位次数 $a$ 与伴随式次数 $b-1$ 相加为 $j$，所以

$$\Omega_j=\bigoplus_{a=0}^{\min(L,j)}\Lambda_a S_{j+1-a},\qquad j=0,\ldots,h-1.$$

基础实现可以串行复用乘法器。计算完检查 $j\ge L$ 的系数全部为零；有效关键方程分子必须满足次数小于 $L$。不能只丢弃这些高项而不检查。

Chien 与卷积在数学上都只依赖 BM 输出，若资源独立可以并行，若共享乘法器就顺序安排。Chien 的运行期递推使用常量乘网络，一拍一个位置需满足异或树时序和错误记录 RAM 的写入能力。初始化各项也要计入时钟预算，不能把常量预乘准备拍隐去。

把扫描中记录的根命中数记为 `err_cnt`，每次零求值记录对应位置并增一；容量满后再出现命中要报溢出。扫描结束要求 `err_cnt==L`。这是必要检查，但第 10 章会解释它和全部伴随式复核也不能排除所有超能力误纠。

### 9.5 Forney 和修正怎样成为可提交的输出

本节把 §7.2 的推导落成共享域乘法器的多拍流程，主流程固定 $\beta=1$。BM 输出和卷积结果已经冻结，Chien 扫描已确认根数等于最终长度 $L$；每条错误记录保存线路位置与根，位置为 $p_a$，根为 $z_a=\alpha^{-(n-1-p_a)}$，$a$ 是错误记录序号。

先按原定位次数构造导数数组：原来的第 $j$ 次系数在 $j$ 为奇数时写到导数数组第 $j-1$ 项，偶数时写零。公式是 $\Lambda'(x)=\Lambda_1+\Lambda_3x^2+\cdots$；数组不能删去中间的零后改变次数。定义两次求值结果及分母逆元为

$$U_a:=\Omega(z_a),\qquad V_a:=\Lambda'(z_a),\qquad I_a:=V_a^{-1}\quad(V_a\ne0).$$

这里 $U_a,V_a,I_a$ 都是域元素；$V_a$ 与第 9.2 节综合征支路状态 $V_j$ 的用途不同。主约定下 $E_a=U_aI_a$。下表每一行是一段有数据依赖的操作，不能把它们当作必然各占一拍。

| 操作阶段 | 输入与操作 | 等待条件与提交结果 | 对应理论 |
|---|---|---|---|
| 载入一条根记录 | 读取 $p_a,z_a$，清零求值累加器，冻结本条记录 | 根与位置在整次幅值运算完成前保持 | §7.2（1） |
| 分子求值 | 按 $\Omega_{L-1},\ldots,\Omega_0$ 从高次到低次做 Horner；每一步是累加值乘 $z_a$ 再异或本项系数 | 一次乘法返回并完成异或后，才提交累加器并推进系数下标；最后保存 $U_a$ | §7.2（2）、（6） |
| 分母求值 | 按导数数组从高次到低次做相同 Horner 操作，仍使用这条记录的 $z_a$ | 最后保存 $V_a$，检查非零；零则拒绝当前候选 | §7.2（4）、（5） |
| 求逆 | 对非零 $V_a$ 发起有限域求逆 | 结果返回后保存 $I_a$；不得提前读下一条根覆盖操作数 | §2.3、§7.2（6） |
| 幅值乘法 | 对 $U_a,I_a$ 发起域乘法 | 返回后保存 $E_a$；零幅值不符合基础有效错误条件 | §7.2（5）、（6） |
| 写错误记录 | 把 $E_a$ 写入与 $p_a$ 相同序号的幅值记录 | 该条记录完成后才推进 $a$；全部记录通过后进入修正阶段 | §7.2（7） |

Horner 的系数循环可以保留高端零系数，也可以从已验证的实际最高次开始；两者结果相同。初始化累加器为零，每步使用旧累加器乘固定根、再异或当前系数，这与第 4.2 节的乘开推导一致。资源并行时可以同时计算 $U_a,V_a$，但必须保证两个结果对应同一条根记录；共享资源时先后计算也不改变公式。

若支持一般根起点 $\beta$，幅值乘法之后还要乘 §7.3 推得的因子 $z_a^{\beta-1}$；零指数返回 1，负指数使用逆元。当前参考 `decode` 固定 $\beta=1$，因此没有这一步。域除法、求逆与整数 `/` 不同；同步查表求逆也要等表输出有效后再提交。

修正后的符号记为 $r_i^{\mathrm{fix}}$；命中位置执行

$$r_{p_a}^{\mathrm{fix}}:=r_{p_a}\oplus E_a,$$

其余位置保持 $r_i^{\mathrm{fix}}:=r_i$。先确认全部位置和幅值，再对每条记录执行“发出 `cw_ram[p_a]` 读地址 → 等待读数据 → 将读数据异或 $E_a$ → 写回同一地址”。同步 RAM 的读出存在延迟，必须在等待期间保持位置和幅值配对；最后一条写回真正完成后，才能启动整块复核。

修正后复核综合征定义为

$$S_j^{\mathrm{post}}:=\sum_{i=0}^{n-1}r_i^{\mathrm{fix}}(\alpha^j)^{n-1-i},\qquad j=1,\ldots,h.$$

这与第 4.1 至 4.2 节的定义和求值流程相同，只换成修正后输入。重新遍历整块 RAM，若任何综合征非零则报失败；若全部为零，标记 `codeword_valid` 并输出前 $k$ 个信息符号或协议要求的整个码字。它表示候选通过检查，不是对超过纠错半径的输入无条件保证恢复原文。

对照 Python 时，`decode` 依次用 `poly_mul(... )[:h]` 得到 `omega`，构造 `deriv`，以 `peval(f,omega,z)` 得到 $U_a$、以 `peval(f,deriv,z)` 得到 `den` 即 $V_a$，再由 `f.div(U_a,den)` 恢复幅值，并执行 `corrected[position] ^= E`。补充脚本 `forney_trace_check.py` 输出卷积和 Horner 的中间值，帮助定位第一个偏离；它不模拟乘法器、求逆器或 RAM 的时钟延迟。

输出受反压时，保持 `out_valid`、符号内容和索引，只有 `out_valid && out_ready` 才推进。失败块如何传递由系统定义，不能让后续模块把失败数据当成功纠正的数据。

<a id="sec-9-6"></a>
### 9.6 延迟和吞吐为何必须分开计算

延迟是一个码块从开始处理到完成输出的时间；吞吐率是持续运行时每秒可处理多少比特。启动间隔（Initiation Interval，II）记为 $\mathrm{II}$，是相邻两个码块开始处理之间的时钟拍数，决定持续吞吐，不必等于单块延迟。下面的 $T$ 都按时钟拍数计算，乘以时钟周期才是秒。

各阶段拍数分别记为：接收伴随式 $T_{\mathrm{syn}}$、最短递推 $T_{\mathrm{BM}}$、求值卷积 $T_\Omega$、位置扫描 $T_{\mathrm{Ch}}$、幅值恢复 $T_{\mathrm{For}}$、修正写回 $T_{\mathrm{fix}}$、整块复核 $T_{\mathrm{verify}}$ 和输出 $T_{\mathrm{out}}$；整块延迟记为 $T_{\mathrm{dec}}$。

在无停顿、单符号接收情况下，$T_{\mathrm{syn}}=n$，它已包含接收时间。所有阶段顺序运行时，完整延迟为

$$T_{\mathrm{dec}}=T_{\mathrm{syn}}+T_{\mathrm{BM}}+T_\Omega+T_{\mathrm{Ch}}+T_{\mathrm{For}}+T_{\mathrm{fix}}+T_{\mathrm{verify}}+T_{\mathrm{out}}.$$

若卷积和 Chien 用独立资源并行，那两项替换成 $\max(T_\Omega,T_{\mathrm{Ch}})$，因为需要二者都完成后才进入 Forney；不是简单把两项都删除。

一拍一位置的 Chien 有 $n$ 个有效扫描拍；复核有 $n$ 个读到有效符号的计算拍，再加 RAM 管线灌入排空。Forney 一次错误需多少拍，取决于求值系数数、共享情况、乘法和求逆延迟，不能一般化成一个错误一拍。

记时钟频率为 $f_{\mathrm{clk}}$（Hz），每拍输入并行符号数为正整数 $P_{\mathrm{in}}$；连续线路的输入需求是 $P_{\mathrm{in}}wf_{\mathrm{clk}}$ 比特每秒。每块包含 $nw$ 比特，持续码字比特吞吐率与有效信息比特吞吐率分别记为 $B_{\mathrm{coded}},B_{\mathrm{info}}$。每个码块的信息比例是第 1.3 节定义的 $R=k/n$，所以

$$B_{\mathrm{coded}}=\frac{nw f_{\mathrm{clk}}}{\mathrm{II}},\qquad B_{\mathrm{info}}=R B_{\mathrm{coded}}.$$

前式由“每次启动处理的比特数”除以“启动时间间隔”得到。延迟很长的多块流水仍可有较小的 $\mathrm{II}$；只有一套共享状态、处理完才收下一块的架构，$\mathrm{II}$ 才接近整块处理时间。PCS（Physical Coding Sublayer，物理编码子层）是物理链路中承担码块与符号编码处理的功能层。高速 PCS 可用双缓冲（一个缓存接收下一块，另一个处理当前块）、多块调度、增加并行符号数或复制慢阶段来匹配输入速率。

<a id="sec-10-1"></a>
### 10.1 超过纠错半径为何可能误纠

在 $\nu\le t$ 时，第 4 章给唯一性，第 5 至 7 章给正确的求解路径，所以基础算法能恢复 $c$。超过半径时，无法从接收串单独判断它到底靠近哪个原始码字。

给一个可直接复现的反例。发送 $c=0$。另一个合法码字取 $c'(z)=g(z)$，因为它当然被 $g$ 整除；在 73 个位置中前 68 个全零，最后五个从高次到低次是 `01 1E D8 E7 74`。

让接收串的最后五个是 `00 00 D8 E7 74`，其他全零。那么它与发送的全零码字相差三个符号，已超过 $t=2$；却只与另一个合法码字相差两个符号。

译码器会找出距离为 2 的 $c'$：定位根数是 2，两个幅值非零，纠正后的全部伴随式为零。每项常规检查都能通过，但恢复的不是发送的全零码字。

因此不能承诺“超过 $t$ 必报错”，也不能把“重算伴随式全零”写成“绝不会误纠”。把接收串纠正成另一个合法码字的情况称为误纠。真实系统可另外使用循环冗余校验（Cyclic Redundancy Check，CRC）：把数据比特多项式除以约定的校验多项式，并携带余数，接收端复算检查。CRC 用于检测错误，不能把任意错误都保证检出；其覆盖条件需独立分析，本文也不假设系统一定具备它。

<a id="sec-10-2"></a>
### 10.2 擦除和交织怎样改变问题条件

擦除是“这个位置不可靠”，位置已经提供给译码器。记已知的擦除位置数为非负整数 $s_{\mathrm{era}}$，非擦除区域中未知位置的错误数为非负整数 $u_{\mathrm{err}}$。若两个候选都在非擦除区域距离接收串至多 $u_{\mathrm{err}}$，它们在非擦除区域最多不同 $2u_{\mathrm{err}}$ 个位置，在擦除区域最多再不同 $s_{\mathrm{era}}$ 个。由距离至少 $h+1$，只要

$$2u_{\mathrm{err}}+s_{\mathrm{era}}\le h,$$

两个不同候选就不能同时成立。这给出错误加擦除的唯一性条件。它不自动为本文的纯错误 RTL 增加擦除能力；若需要支持擦除，还要引入擦除定位多项式并修改关键方程流程。

理想的按符号循环交织，将相邻符号依次分给 $J$ 个码块，正整数 $J$ 称为交织深度。连续受损的符号位置数记为非负整数 $b_{\mathrm{burst}}$；这段连续受损位置被分配到每块的数量至多 $\lceil b_{\mathrm{burst}}/J\rceil$。如果这个值不超过 $t$，每块都落在纠错半径内。这个计数依赖明确的交织布局和符号对齐；不能把 $tw$ 比特直接当作任意起点突发的统一保证，跨符号边界可能额外碰到一个符号。

交织不改变单个 RS 码块的 $d_{\min}$，它改变错误如何分散，并增加缓冲与时延。位滑动、符号丢失和帧边界错误仍需由前级同步或明确的擦除接口处理。

<a id="sec-10-3"></a>
### 10.3 用参考模型核验数值与 RTL 的分工

参考模型是用于计算预期算法结果的软件程序；它给符号值和中间量，不模拟每拍 RAM 或握手时序。断言（assertion）是必须满足的检查条件，条件为假便报错并停止本次验证。

在 Python 3 环境中运行同目录脚本：

```text
python fec_reference_check.py
```

脚本不依赖第三方包，包含三种独立的有限域乘法计算路径：移位归约、完整无进位多项式乘积后长归约、指数表乘法。在两组域中枚举所有输入对并比较结果，同时枚举全部非零逆元。

编码由长除法与反馈寄存器交叉核验；伴随式由逐位置直接加权与 Horner 交叉核验；Chien 由逐项常量递推与直接多项式求值逐点核验；归一化 BM 与免除法 BM 比较完整纠正结果。高斯消元（Gaussian elimination）通过交换方程、用非零系数除整条方程，再用其倍数相加消去其他方程的对应未知量；这些操作可逆，因此不改变解集。在域上除法仍是乘逆元，消元相加仍是 XOR。若消到一条左边全零而右边非零的方程，候选长度便不可行。参考脚本从长度 0 起逐个尝试，把所需递推写成方程，找到第一个可行长度。它还把任意短前缀的 BM 长度与这一独立的有限域高斯消元最短长度比较，以覆盖 $L\ne\deg C$ 的情况。

随机码块覆盖从无错到满能力的每一种错误数，每种八个独立消息；并专门构造首伴随式抵消、中途零残差和超能力误纠反例。所有检查使用断言，失败时脚本停止，不能仅靠打印“成功”掩盖失败。

本次实际检查结果为：8 比特域枚举 65,536 个乘法输入对，9 比特域枚举 262,144 个；BM 与高斯消元核对 2,856 个前缀；两组 RS 共检查 152 个随机码块，每个码块同时走归一化和免除法译码。全部断言通过。这些数字由脚本的枚举范围和输出可直接复现。

这些检查验证的是数学算法和文中数值，不是已完成 RTL 的仿真或综合。在把第 9 章写成具体模块后，至少还应验证：输入和输出随机停顿不改变码字结果；同步 RAM 延迟对齐；最后一个符号计入伴随式；每一轮残差使用旧系数；零分母和数组溢出正确报错；复位或中断不会把上一块状态带入下一块。随后再检查综合后的面积、时序与持续吞吐。

<a id="sec-10-4"></a>
### 10.4 从本文走向一个实际设计

实际设计先固定域基、符号位序、生成元、根的起始指数、系数方向、截短位置和发送顺序；这些决定了常量网、ROM 内容与接口含义。之后选择输入符号并行度与译码资源，按第 9.6 节计算块启动间隔，再决定缓冲深度。

可以先独立实现有限域单元和编码器，因为它们最容易用枚举与合法码字检查核验；再实现伴随式模块；接着用本篇四轮账目逐拍对照 BM；最后串起位置、幅值和整块复核。在可纠输入上，最终的数学链条是：$L=\nu$，$\Lambda$ 给出全部错误位置，$\Omega/\Lambda'$ 给出全部错误幅值，逐位置 XOR 恢复码字。

本文最需要保持的三个区分是：域元素的值与指数、迭代长度与实际多项式次数、候选通过校验与无条件恢复原文。它们分别对应算术正确性、BM 状态正确性和系统错误状态的含义。

### A.3 BM 逐轮记录和应保持的关系

`bm` 返回三元组 `(C,L,rows)`。其中 `C` 是最终归一化并裁掉尾部零系数的升幂列表，`L` 是最终递推长度；`rows` 保存归一化前的每轮记录。第 $N$ 轮记录的结构为：

```text
(N, before, d, ratio, growing, L_after, C_after)
before = (C_before, L_before, shift_before, b_before, B_before)
```

比较 RTL 或另一份模型时，先匹配轮号，再分别比较残差与更新前状态，最后检查更新结果。不要将 `L_before` 与 `L_after` 混用，也不要将非增长轮保存的旧 `B,b` 误认为本轮生成的新快照。

| 关系或检查 | 成立阶段与条件 | 代码行为 | 理论依据 |
|---|---|---|---|
| $H=L_B+L$，$s=N-H$ | 每轮开始，包括初始化哨兵 | `bm` 入口两条整数状态断言 | §6.3、§6.5 |
| $\deg C\le L$，$\deg B\le L_B$ | 每轮开始及更新后 | `bm` 的次数断言 | §6.1、§6.3 |
| $\Delta_j(C)=0$ 对 $j=L+1,\ldots,N$ | 本轮提交后；区间可能为空 | `bm` 更新后逐条残差断言 | §6.3 至 §6.5 |
| $\Delta_H(B)=b\ne0$ | 真实快照 $H\ge1$；不能套到哨兵 $H=0$ | 真实增长轮保存旧 `C` 和同轮非零 `d` | §6.3、§6.5 |
| $C=\Lambda$、$L=\nu$ | 完整处理 $h$ 个伴随式且实际错误数 $\nu\le t$ | `main` 将恢复码字和错误清单与注入真值比较 | §5.3、§6.5 |
| $\Omega_j=0$ 对 $j\ge L$ | BM 出口候选必须满足 | `decode` 检查 `omega[L:]` | §5.2、§9.4 |
| Chien 增量值等于直接求值 | 每个扫描位置 | `decode` 中 `direct==inc` 断言 | §7.1 |
| 根数等于最终次数；导数非零；复核全零 | 基础译码的候选接受条件 | `decode` 的失败出口和最终复核 | §7.2、§9.4 至 §9.5 |

参考模型为记录逐轮比例，仍在两种模式下计算 `ratio=d/b`，出口也进行归一化。`inversionless=True` 指系数更新使用第 6.6 节的免除法形式，不表示这份 Python 程序完全没有求逆调用。

本文第 7.3 节证明了通用 FCR 公式；当前 `decode` 固定使用 FCR 为 1 的完整流程。`generator` 和 `syndromes` 虽有 `first_root` 参数，也不能据此认定改变该参数后整个译码器已经支持其他 FCR。

### B.3 向用户报告问题的证据格式

定位结果至少包含：固定的输入和约定；最早偏离的阶段与轮号或位置；对应的预期关系和论文小节；实际代码函数与当前行号；能区分假设的复现结果。还没有实际 RTL、波形或完整输入时，指出仍缺的证据，不把一个可能原因写成已确定的根因。
